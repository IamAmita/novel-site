# Python Django 環境セットアップ内容

## 概要

Python + Django + React 構成の開発環境を Docker Compose で構築しました。

## Docker サービス構成

### `db`（PostgreSQL）

- イメージ: `postgres:15-alpine`
- ポート: `5432:5432`
- 初期化SQL: `service/postgres/init/01-init-database.sql`（uuid-ossp, pg_trgm 拡張有効化）
- ヘルスチェック: `pg_isready` で DB 起動確認

### `redis`（Redis）

- イメージ: `redis:7-alpine`
- ポート: `6379:6379`
- ヘルスチェック: `redis-cli ping`

### `backend`（Django）

- ベース: `python:3.11-slim`
- ポート: `8000:8000`
- 起動順序: `db`, `redis` の healthcheck 完了後に起動
- entrypoint: マイグレーション実行 → 開発サーバー起動
- ソースコード: `./backend` をボリュームマウント（ホットリロード対応）

### `frontend`（React + Vite）

- ベース: `node:20-alpine`
- ポート: `3000:3000`
- 起動順序: `backend` 起動後に起動
- ソースコード: `./frontend` をボリュームマウント（ホットリロード対応）
- `/api` へのリクエストは Vite プロキシ経由で `backend:8000` に転送

## Django 設定ポイント

### 環境変数管理

`python-decouple` を使用し、`.env` ファイルから設定を読み込みます。

```python
SECRET_KEY = config('SECRET_KEY', default='...')
DEBUG = config('DEBUG', default=True, cast=bool)
```

### データベース

PostgreSQL を使用。`DB_HOST` のデフォルト値は Docker サービス名 `db`。

### キャッシュ

`django-redis` を使用し Redis に接続。

### CORS

`django-cors-headers` を使用。`CORS_ALLOWED_ORIGINS` 環境変数でフロントエンドのオリジンを許可。

## フロントエンド設定ポイント

### Vite プロキシ

`/api` へのリクエストを Django バックエンドに転送します。
ブラウザからは `localhost:3000` のみ使用します。

```typescript
proxy: {
  '/api': {
    target: 'http://backend:8000',
    changeOrigin: true,
  },
},
```

### 初期表示画面（App.tsx）

サービス未実装のため、サイト名・技術スタック・「準備中」メッセージを表示するプレースホルダー画面。
