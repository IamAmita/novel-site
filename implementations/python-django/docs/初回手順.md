# 初回起動手順

## 前提条件

以下がインストール済みであること。

- Docker Desktop（v24 以上推奨）
- Git

---

## 手順

### 1. リポジトリのクローン（未実施の場合）

```bash
git clone https://github.com/IamAmita/novel-site.git
cd novel-site
```

### 2. python-django ディレクトリに移動

```bash
cd implementations/python-django
```

### 3. 環境変数ファイルの作成

`.env.example` をコピーして `.env` を作成します。
開発環境はデフォルト値のままで動作します。

```bash
# macOS / Linux
cp .env.example .env

# Windows (PowerShell)
Copy-Item .env.example .env
```

> **注意**: `.env` は `.gitignore` により Git 管理対象外です。

### 4. Docker コンテナのビルド・起動

初回はイメージのビルドが発生するため数分かかります。

```bash
docker compose up --build
```

バックグラウンドで起動する場合:

```bash
docker compose up --build -d
```

### 5. 起動確認

以下の URL にアクセスして動作を確認します。

| サービス | URL | 説明 |
|---------|-----|------|
| フロントエンド | http://localhost:3000 | React 初期画面 |
| バックエンド | http://localhost:8000 | Django（「It worked!」ページ） |
| Django Admin | http://localhost:8000/admin | 管理画面 |

---

## 停止・再起動

### コンテナ停止

```bash
docker compose down
```

### DB データも削除して完全リセット

```bash
docker compose down -v
```

### 再起動（ビルド不要）

```bash
docker compose up -d
```

---

## ログ確認

```bash
# 全サービスのログ
docker compose logs -f

# バックエンドのみ
docker compose logs -f backend

# フロントエンドのみ
docker compose logs -f frontend
```

---

## Django 管理コマンド

コンテナ起動中に以下のコマンドを実行できます。

```bash
# スーパーユーザー作成
docker compose exec backend python manage.py createsuperuser

# マイグレーション作成（アプリ追加後）
docker compose exec backend python manage.py makemigrations

# マイグレーション実行
docker compose exec backend python manage.py migrate

# Django シェル
docker compose exec backend python manage.py shell
```

## PowerShell スクリプトを使う場合（Windows）

`service/scripts/` にスクリプトが用意されています。

```powershell
# 起動（初回ビルドあり）
.\service\scripts\start-local.ps1 -Build

# 起動（2回目以降）
.\service\scripts\start-local.ps1

# 停止
.\service\scripts\start-local.ps1 -Down

# ヘルスチェック
.\service\scripts\health-check.ps1
```

## トラブルシューティング

### ポートが使用中の場合

他のプロセスが 3000, 8000, 5432, 6379 を使用している場合は、
`docker-compose.yml` の `ports` を変更してください。

```yaml
ports:
  - "3001:3000"  # 例: 3001 に変更
```

### DB 接続エラーが出る場合

DB の起動に時間がかかっている可能性があります。
ログを確認し、`db` コンテナが healthy になってから `backend` が起動しているか確認してください。

```bash
docker compose ps
```

### イメージを完全に再ビルドしたい場合

```bash
docker compose build --no-cache
docker compose up -d
```
