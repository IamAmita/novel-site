## 1. プロジェクト概要

### 1.1 目的

設定管理・共同著作に対応した小説投稿サイトを、Python / Django + React で実装する。
本実装は「5言語・5DB 学習プロジェクト」の **Phase 1（基準実装）** として位置づけ、後続実装の仕様基準となる。

### 1.2 スコープ

本ドキュメントは **Python / Django 実装版** の要件を定義する。
他言語実装との共通仕様は `shared/` および `docs/` を参照すること。

### 1.3 開発方針

- 品質重視・納期制限なし
- 個人開発（1名）
- Docker による環境構築
- 段階的実装（Phase 1 → 2 → 3）

## 3. 非機能要件

### 3.1 パフォーマンス

| 指標 | 目標値 |
|------|--------|
| ページ読み込み（初回） | 3秒以内 |
| ページ遷移 | 1秒以内 |
| API レスポンス | 500ms以内 |
| DB クエリ応答 | 1秒以内 |
| 検索結果表示 | 2秒以内 |
| 画像アップロード（10MB） | 5秒以内 |
| 同時接続数（初期目標） | 100ユーザー |
| 同時接続数（将来目標） | 1,000ユーザー |

### 3.2 可用性

| 指標 | 目標値 |
|------|--------|
| システム稼働率 | 99% 以上 |
| 計画メンテナンス | 月1回・2時間以内 |
| 障害復旧時間（軽微） | 4時間以内 |
| 障害復旧時間（重要） | 2時間以内 |
| 障害復旧時間（緊急） | 30分以内 |
| バックアップ頻度 | 日次（差分）・週次（完全） |
| バックアップ保持期間 | 30日間 |

### 3.3 セキュリティ

| 要件 | 詳細 |
|------|------|
| 通信暗号化 | HTTPS / TLS 必須 |
| 認証 | JWT（アクセストークン + リフレッシュトークン） |
| パスワード | bcrypt によるハッシュ化 |
| アカウントロック | ログイン失敗5回でロック |
| XSS 対策 | 入力値のエスケープ、Content Security Policy |
| CSRF 対策 | Django CSRF ミドルウェア + SameSite Cookie |
| SQLインジェクション対策 | Django ORM 使用（生SQL最小化） |
| 個人情報 | メールアドレスは他ユーザーに非公開 |
| 2段階認証 | Phase 3 で実装（Email / SMS / TOTP） |
| ログイン履歴 | Phase 3 で実装 |

### 3.4 拡張性・保守性

| 要件 | 詳細 |
|------|------|
| データ容量 | 10GB 以上に対応可能な設計 |
| モジュール化 | Django アプリ単位での機能分割 |
| API 後方互換性 | バージョニング（/api/v1/）で管理 |
| テストカバレッジ | 80% 以上（バックエンド） |
| コード規約 | PEP8 準拠、Black によるフォーマット |

### 3.5 ユーザビリティ

| 要件 | 詳細 |
|------|------|
| レスポンシブ | PC（1024px+）・タブレット（768px+）・スマートフォン |
| アクセシビリティ | キーボード操作対応、スクリーンリーダー基本対応 |
| エラーメッセージ | ユーザーが理解できる日本語メッセージ |
| 主要機能到達 | 3クリック以内 |
