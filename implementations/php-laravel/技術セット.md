### 起動コマンド

### 環境別起動方法

#### 🐧 Linux/Mac環境
```bash
./vendor/bin/sail up -d
./vendor/bin/sail artisan migrate
./vendor/bin/sail npm run dev
```

#### 🪟 Windows環境（推奨）

##### Step 1: 環境変数設定
```powershell
# PowerShellで実行（毎回必要）
$env:WWWUSER=1000          # LinuxユーザーID
$env:WWWGROUP=1000         # LinuxグループID  
$env:MYSQL_EXTRA_OPTIONS=  # MySQL追加オプション（空文字）
```

##### Step 2: Docker Compose起動
```powershell
# コンテナ起動
docker-compose up -d

# 起動確認
docker-compose ps
```

##### Step 3: Laravel初期設定
```powershell
# データベースマイグレーション
docker-compose exec laravel.test php artisan migrate

# フロントエンド開発サーバー起動
docker-compose exec laravel.test npm run dev
```

#### 🚨 Windows環境での重要な注意点

1. **WSL関連エラー**
   - `./vendor/bin/sail` コマンドでWSLエラーが発生
   - **解決策**: `docker-compose` を直接使用

2. **パス区切り文字**
   - Windows: `\` (バックスラッシュ)
   - Docker内: `/` (スラッシュ)
   - **影響**: ファイルパス指定時に注意

3. **権限問題**
   - `WWWUSER`, `WWWGROUP` の設定必須
   - **理由**: Docker内のLinux環境とのユーザーID整合

4. **PowerShell実行ポリシー**
   ```powershell
   # 必要に応じて実行ポリシー変更
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   ```

### 🔧 Windows環境トラブルシューティング

#### よくある問題と解決策

##### 1. WSLエラー
```
エラー: CreateProcessParseCommon:1008: getpwuid(0) failed 2
```
**解決策**: 
```powershell
# Laravel Sailを使わずdocker-composeを直接使用
docker-compose up -d
```

##### 2. 環境変数エラー
```
warning: The "WWWUSER" variable is not set
```
**解決策**:
```powershell
# 毎回PowerShellで設定
$env:WWWUSER=1000; $env:WWWGROUP=1000; docker-compose up -d
```

##### 3. ポート競合エラー
```
Error: Port 3306 is already in use
```
**解決策**:
```powershell
# 使用中のポートを確認
netstat -ano | findstr :3306

# .envファイルでポート変更
FORWARD_DB_PORT=3307
```

##### 4. Docker Desktop未起動
```
Error: Cannot connect to the Docker daemon
```
**解決策**:
1. Docker Desktopアプリケーションを起動
2. システムトレイでDockerアイコンを確認

##### 5. メモリ不足（Elasticsearch）
```
Elasticsearch: max virtual memory areas vm.max_map_count [65530] is too low
```
**解決策**:
```powershell
# Docker Desktop設定でメモリを4GB以上に設定
# Settings → Resources → Advanced → Memory
```

## 🎨 フロントエンド技術

### Vue.js + Inertia.js
```javascript
// 小説表示コンポーネント例
<template>
  <div class="novel-viewer">
    <div class="controls">
      <button @click="toggleOrientation">
        {{ isVertical ? '横書き' : '縦書き' }}
      </button>
    </div>
    <div 
      :class="{ 'vertical-text': isVertical }"
      v-html="processedContent"
    ></div>
  </div>
</template>

<script>
export default {
  props: ['content'],
  data() {
    return { isVertical: false };
  },
  computed: {
    processedContent() {
      // 彼|かれ → <ruby>彼<rt>かれ</rt></ruby>
      return this.content.replace(
        /([^\|]+)\|([^\s]+)/g, 
        '<ruby>$1<rt>$2</rt></ruby>'
      );
    }
  }
};
</script>
```

#### 基本設定
```php
// config/scout.php
'elasticsearch' => [
    'index' => env('ELASTICSEARCH_INDEX', 'novels'),
    'hosts' => [
        env('ELASTICSEARCH_HOST', 'localhost:9200'),
    ],
],
```

#### 日本語解析設定
```php
// Elasticsearchインデックス設定
{
    "settings": {
        "analysis": {
            "analyzer": {
                "japanese": {
                    "type": "custom",
                    "tokenizer": "kuromoji_tokenizer",
                    "filter": ["kuromoji_baseform", "lowercase"]
                }
            }
        }
    },
    "mappings": {
        "properties": {
            "title": {"type": "text", "analyzer": "japanese"},
            "content": {"type": "text", "analyzer": "japanese"}
        }
    }
}
```

#### 小説モデル
```php
class Novel extends Model
{
    use Searchable;
    
    public function searchableAs()
    {
        return 'novels_index';
    }
    
    public function toSearchableArray()
    {
        return [
            'title' => $this->title,
            'content' => $this->content,
            'author_name' => $this->user->name,
            'genre' => $this->genre,
            'status' => $this->status,
            'created_at' => $this->created_at->toISOString(),
        ];
    }

    // 検索条件のカスタマイズ
    public function searchableQuery()
    {
        return $this->where('status', 'published');
    }
}

// 検索実行例
$results = Novel::search('恋愛 学園')
    ->where('status', 'published')
    ->orderBy('created_at', 'desc')
    ->get();
```

```php
// プロフィール画像処理
public function processAvatar($file)
{
    $filename = uniqid() . '.webp';
    
    // メイン画像
    Image::make($file)
        ->fit(400, 400)
        ->encode('webp', 80)
        ->save(storage_path('app/public/avatars/' . $filename));
    
    // サムネイル
    Image::make($file)
        ->fit(100, 100)
        ->save(storage_path('app/public/avatars/thumb_' . $filename));
    
    return $filename;
}
```

## 📝 テキスト処理

### ルビ記法システム
```php
// 入力: 彼|かれ は美しい|うつくしい 花を見た
// 出力: <ruby>彼<rt>かれ</rt></ruby>は<ruby>美しい<rt>うつくしい</rt></ruby>花を見た

public function convertRuby($text)
{
    return preg_replace(
        '/([^\|]+)\|([^\s]+)/u',
        '<ruby>$1<rt>$2</rt></ruby>',
        $text
    );
}
```

### UX重視の設計
- **作者**: `彼|かれ`記法で高速入力
- **読者**: 縦書き・横書き切り替え、フォントサイズ調整
