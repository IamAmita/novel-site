# ユーザーストーリー

**目的**: 技術に依存しない「何を作るか」の定義  
**対象**: 全実装で共通して実現すべき機能

---

## 📖 読者（Reader）のストーリー

### 小説閲覧
- **As a** 読者  
- **I want to** 小説を快適に読む  
- **So that** 物語に集中できる

#### 受け入れ条件
- [ ] 縦書き・横書きの切り替えができる
- [ ] フォントサイズを調整できる
- [ ] ルビ（ふりがな）が正しく表示される
- [ ] ページネーションまたは連続スクロールで読める
- [ ] ブックマーク機能で読書位置を保存できる

### 小説検索・発見
- **As a** 読者  
- **I want to** 興味のある小説を見つける  
- **So that** 新しい作品に出会える

#### 受け入れ条件
- [ ] タイトル・作者名・内容で検索できる
- [ ] ジャンル・タグで絞り込み検索ができる
- [ ] 人気順・更新順・評価順でソートできる
- [ ] 関連作品・おすすめ作品が表示される

### ユーザー登録・プロフィール
- **As a** 読者  
- **I want to** アカウントを作成・管理する  
- **So that** 個人設定を保存し、作者をフォローできる

#### 受け入れ条件
- [ ] メールアドレスでユーザー登録できる
- [ ] プロフィール情報を設定・更新できる
- [ ] 読書履歴・お気に入りを管理できる
- [ ] フォロー・フォロワー機能を利用できる

---

## ✍️ 作者（Author）のストーリー

### 小説投稿・編集
- **As a** 作者  
- **I want to** 小説を投稿・編集する  
- **So that** 読者に作品を届けられる

#### 受け入れ条件
- [ ] 小説のタイトル・あらすじ・本文を入力できる
- [ ] 章・話の構成で作品を管理できる
- [ ] 下書き・公開・限定公開の状態を設定できる
- [ ] ルビ記法（彼|かれ）で入力できる
- [ ] 表紙画像をアップロードできる

### 設定管理
- **As a** 作者  
- **I want to** 作品の設定を詳細に管理する  
- **So that** 世界観に一貫性を保てる

#### 受け入れ条件
- [ ] キャラクター設定（名前・外見・性格・関係性）を管理できる
- [ ] 世界設定（場所・時代・ルール）を管理できる
- [ ] 設定間の関係性を視覚化できる
- [ ] 設定を作品本文から参照できる
- [ ] 設定の公開・非公開を制御できる

### 共同創作
- **As a** 作者  
- **I want to** 他の作者と共同で作品を作る  
- **So that** より豊かな作品を創作できる

#### 受け入れ条件
- [ ] 他の作者を共同編集者として招待できる
- [ ] 役割・権限を設定できる（編集・閲覧・設定管理等）
- [ ] 変更履歴・編集ログを確認できる
- [ ] コメント・提案機能で意見交換できる

---

## 👥 管理者（Admin）のストーリー

### サイト管理
- **As a** 管理者  
- **I want to** サイトを適切に運営する  
- **So that** 安全で快適な環境を提供できる

#### 受け入れ条件
- [ ] ユーザー・作品・コメントを管理できる
- [ ] 不適切なコンテンツを削除・制限できる
- [ ] 利用状況・統計情報を確認できる
- [ ] 規約違反の報告を処理できる
- [ ] システムの監視・メンテナンスができる

---

## 🎯 ビジネス価値

### 主要価値提案
1. **設定管理の充実**: 他サイトにない詳細な設定管理機能
2. **共同創作支援**: 複数人での創作プロセス支援
3. **読書体験の最適化**: 縦書き・ルビ対応の快適な読書環境
4. **創作コミュニティ**: 作者同士・読者との交流促進

### 成功指標
- **ユーザー満足度**: 継続利用率・リピート率
- **コンテンツ品質**: 投稿作品数・完結作品率
- **コミュニティ活性度**: コメント・評価・フォロー数
- **技術評価**: ページ表示速度・システム安定性

---

**更新ルール**: 新機能追加時は必ずユーザーストーリーを定義  
**管理責任**: プロダクトオーナー（全実装共通）
