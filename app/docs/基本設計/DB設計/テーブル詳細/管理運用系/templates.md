# templates テーブル詳細（テンプレート管理）

---

## 概要
各種通知やメッセージなどで利用するテンプレートを管理するテーブルです。種別（class_id）はmaster_classes.idを参照します。

---

## テーブル定義

| 属性名      | 型      | 必須 | 一意 | 説明                                 |
|-------------|---------|------|------|--------------------------------------|
| id          | int     | ○    | ○    | テンプレートID（主キー）             |
| class_id    | int     | ○    |      | 種別ID（master_classes.idを参照）    |
| name        | varchar | ○    |      | テンプレート名                       |
| subject     | varchar | ○    |      | 件名                                 |
| body        | text    | ○    |      | 本文                                 |
| description | text    |      |      | 説明・備考                           |
| created_at  | datetime| ○    |      | 登録日時                             |
| updated_at  | datetime|      |      | 更新日時                             |

---

## インデックス

| インデックス名 | 種類   | 説明           | カラム    |
|----------------|--------|----------------|-----------|
| PRIMARY KEY    | 主キー | 主キー         | id        |
| INDEX          | 通常   | 種別ID検索用   | class_id  |

---

## 設計補足
- class_idはmaster_classes.idを参照する外部キーです。
- nameはテンプレートの識別名です。
- subject, bodyで通知やメッセージの内容を管理します。
- descriptionで用途や備考を管理できます。
- created_atで登録日時、updated_atで更新日時を記録します。
- 新しいテンプレートを追加する場合は、本テーブルに1行追加してください。

---

| id | class_id | name         | subject      | body         | description | created_at          | updated_at          |

|... | ...      | ...          | ...          | ...         | ...         | ...                 | ...                 |

---

## 関連テーブル
- master_classes: class_idで参照（種別管理）
- operation_histories: テンプレートの履歴管理などで参照

---

## 備考
- テンプレートの拡張や内容変更も容易です。
