# templates テーブル詳細

---

## 概要
システム全体のテンプレートを管理するテーブルです。通知、作品、設定、メールなど、各種テンプレートの種別、番号、言語、テンプレート文などを含みます。

---

## テーブル定義

| 属性名             | 型         | 必須 | 一意 | 説明                                 |
|--------------------|------------|------|------|--------------------------------------|
| id                 | int        | ○    | ○    | テンプレートID（主キー）             |
| template_type      | tinyint    | ○    |      | テンプレート種別                     |
| template_number    | tinyint    | ○    |      | テンプレート番号                     |
| language           | tinyint    | ○    |      | 言語コード                           |
| template_text      | text       | ○    |      | テンプレート文                       |
| is_active          | tinyint    | ○    |      | 有効/無効フラグ                      |
| created_at         | datetime   | ○    |      | 作成日時                             |
| updated_at         | datetime   |      |      | 更新日時                             |

---

## インデックス

| インデックス名 | 種類 | 説明 | カラム |
|----------------|------|------|--------|
| PRIMARY KEY | 主キー | テンプレートIDの主キー | id |
| UNIQUE | 複合一意 | テンプレート種別・番号・言語の一意制約 | template_type, template_number, language |
| INDEX | 通常 | テンプレート種別検索用 | template_type |
| INDEX | 通常 | テンプレート番号検索用 | template_number |
| INDEX | 通常 | 言語検索用 | language |
| INDEX | 通常 | 有効/無効フラグ検索用 | is_active |
| INDEX | 複合 | 種別・番号検索用 | template_type, template_number |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 一意制約
- `template_type, template_number, language`: テンプレート種別・番号・言語の組み合わせは一意である必要があります

### チェック制約
- `template_type`: 0～6のいずれかである必要があります
- `template_number`: 0～127のいずれかである必要があります
- `language`: 0、1、2のいずれかである必要があります
- `is_active`: 0または1の値のみ許可

---

## 設計補足

### テンプレート種別（template_type）
- `0`: 通知テンプレート
- `1`: 作品テンプレート（作品説明、章タイトルなど）
- `2`: 設定テンプレート（ユーザープロフィール、サイト設定など）
- `3`: メールテンプレート
- `4`: システムメッセージテンプレート
- `5`: ヘルプ・FAQテンプレート
- `6`: エラーメッセージテンプレート

### テンプレート番号（template_number）
- テンプレートの作成順に割り当てられる連番
- 0～127の範囲で管理
- テンプレート種別内での識別子として使用
- 例：通知系テンプレートの1番目、2番目...

### 言語コード（language）
- `0`: 日本語（ja）
- `1`: 英語（en）
- `2`: 中国語（簡体字）（zh）

### テンプレート文（template_text）
- 通知の表示文
- パラメータは`{parameter_name}`形式で記述
- 例：'{user_name}があなたのコメントにいいねしました'
- サーバーサイドでパラメータを解決して表示

### 有効/無効フラグ（is_active）
- `0`: 無効（使用停止）
- `1`: 有効（使用中）

## 関連テーブル

- `notifications`: 1対多の関係（通知種別からテンプレートを特定）
- その他のテーブル: 各種機能でテンプレートを使用

---

## 運用上の注意点

1. **テンプレート管理**: 新しい通知種別追加時はテンプレートも同時に作成
2. **多言語対応**: 各言語のテンプレートを漏れなく作成
3. **番号管理**: テンプレート種別内で連番を管理
4. **バージョン管理**: テンプレート変更時は履歴を保持
5. **パフォーマンス**: テンプレートのキャッシュ機能を実装
