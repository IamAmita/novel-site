# 統合タグテーブル（tags）

---

## 概要
世界で使用するタグを統合管理するテーブル。運営作成のシステムタグとユーザー作成の独自タグを1つのテーブルで管理し、作成者種別による権限管理により、運営タグの保護とユーザータグの自由な管理を実現する。

---

## テーブル定義

| 属性名           | 型            | 必須 | 一意 | 説明                                     |
|------------------|---------------|------|------|------------------------------------------|
| id               | int           | ○    | ○    | タグID（主キー）                         |
| name             | varchar(100)  | ○    | ○    | タグ名（半角英数字のみ）                 |
| description      | text          |      |      | タグの説明                               |
| creator_type     | tinyint       | ○    |      | 作成者種別（0:運営, 1:ユーザー）         |
| created_by       | int           |      |      | 作成者ID                                |
| class_id         | int           | ○    |      | マスタクラスID（外部キー）               |
| is_active        | tinyint(1)    | ○    |      | アクティブフラグ（0:非アクティブ, 1:アクティブ） |
| created_at       | datetime      | ○    |      | 作成日時                                 |
| updated_at       | datetime      | ○    |      | 更新日時                                 |

|----------------------------------|------|-------------------|----------------------|
| PRIMARY KEY                     | 主キー | タグIDの主キー     | id                   |
| INDEX                           | 通常 | 作成者種別検索用   | creator_type          |
| INDEX                           | 通常 | 作成者検索用       | created_by            |
| INDEX                           | 通常 | タグ名検索用       | name                  |
| INDEX                           | 通常 | クラス検索用       | class_id              |
| INDEX                           | 通常 | アクティブ検索用   | is_active             |
| INDEX                           | 通常 | 作成日時検索用     | created_at            |
| INDEX                           | 複合 | 作成者種別・アクティブ検索用 | creator_type, is_active |
| INDEX                           | 複合 | 作成者・タグ名検索用 | created_by, name |
| UNIQUE                          | 一意 | タグ名の一意性     | name                  |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 外部キー制約
- `created_by` → `users.id`
- `class_id` → `master_classes.id`

### 一意制約
- `name`: タグ名は一意である必要があります

### チェック制約
- `creator_type` IN (0, 1)
- `is_active` IN (0, 1)

## 設計補足

### 作成者種別による権限管理
- **運営タグ** (`creator_type = 0`): 運営が作成、編集・削除不可、保護対象
- **ユーザータグ** (`creator_type = 1`): ユーザーが作成、作成者のみ編集・削除可能
- 権限チェックは作成者種別と作成者IDで判定

### タグクラス管理
- マスタクラスを参照してタグを分類（必須）
- 例：作品用、設定用、メモ用など
- タグの整理と管理を容易にする
- すべてのタグが適切に分類されることで、検索・フィルタリングの効率化
- 運営側でのタグ管理と統計分析の向上

### タグ名の半角制限
- 半角英数字とアンダースコアのみ使用可能
- 全角文字の使用を禁止
- データの一貫性と検索精度の向上
- 国際化対応と外部システム連携の容易さ
- **制御方法**: アプリケーション側での入力チェック（DB側では制約なし）

### グローバル一意性
- システム全体でタグ名の重複を防止
- すべてのユーザーで共通のタグ名
- タグの統一性と検索精度の向上
- 運営タグとユーザータグの名前競合を防止

### アクティブ状態管理
- `is_active`で論理削除を実現
- 非アクティブタグは表示・検索対象外
- 関連設定への影響を考慮した削除処理

---

## 権限管理ルール

### 運営タグ（creator_type = 0）
- **作成**: 運営のみ
- **編集**: 不可（保護対象）
- **削除**: 不可（保護対象）
- **閲覧**: 全ユーザー
- **利用**: 全ユーザー

### ユーザータグ（creator_type = 1）
- **作成**: 全ユーザー
- **編集**: 作成者のみ
- **削除**: 作成者のみ（関連設定がない場合）
- **閲覧**: 全ユーザー
- **利用**: 作成者のみ

---

## 関連テーブル

- `setting_tags`: 1対多の関係（設定へのタグ適用）
- `users`: 多対1の関係（タグ作成者）
- `master_classes`: 多対1の関係（タグの分類）

---

## 運用上の注意点

1. **権限管理**: 作成者種別に応じた適切な権限チェック
2. **データ整合性**: タグ削除時の関連設定への影響
3. **パフォーマンス**: 適切なインデックス設計
4. **運営タグの保護**: 誤削除・誤編集の防止
5. **アクティブ状態**: 非アクティブタグの適切な処理
6. **グローバル一意性**: タグ名の重複防止と統一性の確保
7. **クラス管理**: タグクラスの適切な分類と管理（必須）
8. **デフォルトクラス**: ユーザーが迷った場合のデフォルトクラス設定
9. **半角制限**: アプリケーション側でのタグ名半角英数字制限の実装
10. **既存データ対応**: 全角文字を含む既存タグの半角化処理

---

## 注意事項

1. **作成者種別**: 運営タグとユーザータグの明確な区別
2. **権限管理**: シンプルで確実な権限制御
3. **パフォーマンス**: 適切なインデックス設計
4. **データ保護**: 運営タグの安全性確保
5. **拡張性**: 将来的な機能追加への対応
6. **グローバル一意性**: タグ名の重複防止と統一性の確保
7. **クラス必須化**: すべてのタグに適切な分類を設定
8. **半角制限**: アプリケーション側でのタグ名半角英数字制限の実装
9. **ユーザビリティ**: 半角制限による入力支援機能の提供
