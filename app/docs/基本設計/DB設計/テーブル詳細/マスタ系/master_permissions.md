# master_permissions テーブル詳細（権限種別マスタ）

---

## 概要
各種権限種別（例：管理者、一般ユーザーなど）を一元管理するマスタテーブルです。

---

## テーブル定義

| 属性名      | 型      | 必須 | 一意 | 説明                 |
|-------------|---------|------|------|----------------------|
| id          | int     | ○    | ○    | 権限種別ID（主キー） |
| display_name| varchar | ○    |      | 表示名（日本語等）   |
| description | text    |      |      | 説明・備考           |
| created_at  | datetime| ○    |      | 登録日時             |

---

## インデックス

| インデックス名 | 種類   | 説明           | カラム |
|----------------|--------|----------------|--------|
| PRIMARY KEY    | 主キー | 主キー         | id     |

---

## 設計補足
- idは主キーです。
- display_nameはUI表示や多言語対応に利用できます。
- descriptionで用途や備考を管理できます。
- created_atで登録日時を記録します。
- 新しい権限種別を追加する場合は、本テーブルに1行追加してください。

---

## 運用例
| id | display_name | description      | created_at          |
|----|--------------|-----------------|---------------------|
| 1  | 管理者       | システム管理者   | 2024-06-01 12:00:00 |
| 2  | 一般ユーザー | 標準利用者       | 2024-06-02 13:00:00 |
|... | ...          | ...             | ...                 |

---

## 関連テーブル
