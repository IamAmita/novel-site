# master_classes テーブル詳細

---

## 概要
システム全体の分類定義を管理するマスタテーブルです。コメント、レビュー、通知、評価、通報などで使用する対象の分類を一元管理し、データの整合性と管理の柔軟性を提供します。

---

## テーブル定義

| 属性名             | 型         | 必須 | 一意 | 説明                                 |
|--------------------|------------|------|------|--------------------------------------|
| id                 | tinyint    | ○    | ○    | 分類ID（主キー）                     |
| name               | varchar    | ○    | ○    | 分類名                               |
| description        | text       |      |      | 詳細説明                             |
| created_at         | datetime   | ○    |      | 作成日時                             |
| updated_at         | datetime   |      |      | 更新日時                             |

---

## インデックス

| インデックス名 | 種類 | 説明 | カラム |
|----------------|------|------|--------|
| PRIMARY KEY | 主キー | 分類IDの主キー | id |
| UNIQUE | 一意 | 分類名の一意制約 | name |

---

## 制約条件

### 主キー制約
- `id`: 手動設定（AUTO_INCREMENT不使用）

### 一意制約
- `name`: 分類名は一意である必要があります

### チェック制約
- `id`: 0～127のいずれかである必要があります

---

## 設計補足

### 分類ID（id）
- `0`: コメント
- `1`: 小説
- `2`: 設定
- `3`: 話（チャプター）
- `4`: レビュー
- `5`: ユーザー
- `6`: グループ

### 分類名（name）
- 管理画面での表示名
- ログやレポートでの表示
- 開発者向けの識別子

### 詳細説明（description）
- 分類の詳細な説明
- 使用場面や制約の記載
- 管理画面での表示用

---

## 初期データ

| id | name | description |
|----|------|-------------|
| 0 | コメント | コメントへの操作（評価、通知、通報） |
| 1 | 小説 | 小説への操作（コメント、レビュー、通知、通報） |
| 2 | 設定 | 設定への操作（コメント、レビュー、通知、通報） |
| 3 | 話（チャプター） | 話への操作（コメント、レビュー、通知、通報） |
| 4 | レビュー | レビューへの操作（評価、通知、通報） |
| 5 | ユーザー | ユーザーへの操作（通知、通報） |
| 6 | グループ | グループへの操作（通知、通報） |

---

## 関連テーブル

- `comments`: 多対1の関係（classを参照）
- `reviews`: 多対1の関係（classを参照）
- `notifications`: 多対1の関係（classを参照）
- `evaluations`: 多対1の関係（classを参照）
- `reports`: 多対1の関係（classを参照）

---

## 運用上の注意点

1. **外部キー制約**: 各テーブルでclassの外部キー制約を設定
2. **追加時の注意**: 新しい分類追加時は関連テーブルの確認
3. **管理画面**: 分類の一覧表示・編集機能を提供
4. **バックアップ**: 定義データの定期的なバックアップ
5. **監査ログ**: 分類の変更履歴を記録
