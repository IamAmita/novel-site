# master_operations テーブル詳細（操作種別マスタ）

---

## 概要
各種操作種別（作成、更新、削除、付与、剥奪など）を一元管理するマスタテーブルです。operation_histories等の履歴テーブルでoperation_idカラムとして参照します。

---

## テーブル定義

| 属性名        | 型      | 必須 | 一意 | 説明                 |
|---------------|---------|------|------|----------------------|
| id            | int     | ○    | ○    | 操作種別ID（主キー） |
| display_name  | varchar | ○    |      | 表示名（日本語等）   |
| description   | text    |      |      | 説明・備考           |
| created_at    | datetime| ○    |      | 登録日時             |

---

## インデックス

| インデックス名 | 種類   | 説明           | カラム |
|----------------|--------|----------------|--------|
| PRIMARY KEY    | 主キー | 主キー         | id     |

---

## 設計補足
- idは履歴テーブルのoperation_idカラムで参照されます。
- display_nameはUI表示や多言語対応に利用できます。
- descriptionで用途や備考を管理できます。
- created_atで登録日時を記録します。
- 新しい操作種別を追加する場合は、本テーブルに1行追加してください。

---

## 運用例
| id | display_name | description      | created_at          |
|----|--------------|-----------------|---------------------|
| 0  | 作成         | 新規作成         | 2024-06-01 12:00:00 |
| 1  | 更新         | 既存データの更新 | 2024-06-02 13:00:00 |
| 2  | 削除         | データの削除     | 2024-06-03 14:00:00 |
| 3  | 付与         | 権限や役割の付与 | 2024-06-04 15:00:00 |
| 4  | 剥奪         | 権限や役割の剥奪 | 2024-06-05 16:00:00 |

---

## 関連テーブル
- operation_histories: operation_idで参照

---

## 備考
- 操作種別の拡張や表示名変更も容易です。
