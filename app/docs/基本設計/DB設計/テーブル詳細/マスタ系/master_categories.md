# マスタカテゴリテーブル（master_categories）

---

## 概要
設定の標準分類を管理するマスターテーブル。システム・運営が提供する標準的なカテゴリ分類を階層構造で管理し、全ユーザーで共通の分類体系を提供する。

---

## テーブル定義

| 属性名           | 型            | 必須 | 一意 | 説明                           |
|------------------|---------------|------|------|--------------------------------|
| id               | int           | ○    | ○    | マスタカテゴリID（主キー）     |
| name             | varchar(100)  | ○    |      | カテゴリ名                     |
| description      | text          |      |      | カテゴリの説明                 |
| parent_id        | int           |      |      | 親カテゴリID（階層構造用）     |
| level            | int           | ○    |      | 階層レベル（0:メイン, 1:サブ） |
| order_in_parent  | int           | ○    |      | 親カテゴリ内での表示順序       |
| created_at       | datetime      | ○    |      | 作成日時                       |

---

## インデックス

| インデックス名           | 種類 | 説明               | カラム                |
|------------------------|------|-------------------|----------------------|
| PRIMARY KEY            | 主キー | マスタカテゴリIDの主キー | id                   |
| INDEX                  | 通常 | 親カテゴリ検索用   | parent_id            |
| INDEX                  | 通常 | 階層レベル検索用   | level                |
| INDEX                  | 通常 | 作成日時検索用     | created_at           |
| INDEX                  | 複合 | 親カテゴリ・表示順序検索用 | parent_id, order_in_parent |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 外部キー制約
- `parent_id` → `master_categories.id` (自己参照)

### チェック制約
- `level` >= 0
- `order_in_parent` >= 0

---

## 設計補足

### 階層構造管理
- `parent_id`と`level`を使用して階層構造を実現
- メインカテゴリ（level = 0）とサブカテゴリ（level = 1）の2階層構造
- 将来的にサブサブカテゴリ（level = 2）への拡張も可能

### 標準分類の提供
- システム・運営による統一された分類体系
- 全ユーザーで共通のカテゴリ分類
- 検索・発見の効率化

### 表示順序
- `order_in_parent`で同階層内での表示順序を管理
- カテゴリの並び替えに対応

---

## 関連テーブル

- `settings`: 1対多の関係（設定のマスタカテゴリ分類）
- `setting_categories`: 1対多の関係（ユーザーカテゴリの親参照）

---

## 運用上の注意点

1. **階層構造**: 親カテゴリの削除時は子カテゴリの処理を考慮
2. **表示順序**: カテゴリの並び替え時の整合性維持
3. **パフォーマンス**: 階層クエリの最適化
4. **データ整合性**: 設定テーブルとの関連性確認
5. **標準分類**: 全ユーザー共通の分類体系の維持

4. **標準分類**: 全ユーザー共通の分類体系の維持
