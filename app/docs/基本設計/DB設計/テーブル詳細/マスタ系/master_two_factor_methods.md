# master_two_factor_methods テーブル詳細

---

## 概要
2段階認証方式（メール、SMS、TOTPなど）を管理するマスタテーブルです。

---

## テーブル定義

| 属性名      | 型      | 必須 | 一意 | 説明                   |
|-------------|---------|------|------|------------------------|
| id          | tinyint | ○    | ○    | 認証方式ID（主キー）   |
| code        | varchar | ○    | ○    | 認証方式コード         |
| name        | varchar | ○    |      | 認証方式名             |
| created_at  | datetime| ○    |      | 登録日時               |

---

## インデックス

| インデックス名 | 種類 | 説明           | カラム   |
|----------------|------|----------------|----------|
| PRIMARY KEY    | 主キー | 主キー         | id       |
| UNIQUE         | 一意   | コード一意制約 | code     |

---

## サンプルデータ

| id | code  | name         |
|----|-------|--------------|
| 0  | email | メール認証   |
| 1  | sms   | SMS認証      |
| 2  | totp  | TOTP認証     |

---

## 関連テーブル

- `two_factor_auth`: 多対1の関係（2段階認証設定）

---

## 運用上の注意点

- 新しい認証方式を追加する場合は本マスタに登録
