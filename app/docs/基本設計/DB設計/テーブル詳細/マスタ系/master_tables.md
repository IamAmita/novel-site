# master_tables テーブル詳細（テーブル種別マスタ）

---

## 概要
各種エンティティのテーブル情報を管理するマスタテーブルです。id（table_id）は4桁（1000〜9999）の数字で管理します。

---

## テーブル定義

| 属性名        | 型      | 必須 | 一意 | 説明                                 |
|---------------|---------|------|------|--------------------------------------|
| id            | int     | ○    | ○    | テーブルID（主キー、4桁:1000〜9999） |
| table_name    | varchar | ○    |      | テーブル名（英語）                   |
| display_name  | varchar | ○    |      | 表示名（日本語等）                   |
| created_at    | datetime| ○    |      | 登録日時                             |

---

## インデックス

| インデックス名 | 種類   | 説明           | カラム     |
|----------------|--------|----------------|------------|
| PRIMARY KEY    | 主キー | 主キー         | id         |

---

## 設計補足
- idは4桁（1000〜9999）の数字で管理します。
- table_nameは物理テーブル名（英語）を記載します。
- display_nameでUIや管理画面に柔軟に表示できます。
- 新しいテーブル種別を追加する場合は、本テーブルに1行追加してください。

---

## 運用例
| id   | table_name | display_name | created_at          |
|------|------------|--------------|---------------------|
