# master_tables テーブル詳細（テーブル種別マスタ）

---

## 概要
各種テーブルを一元管理するマスタテーブルです。user_histories等の履歴テーブルでテーブルIDの管理に参照します。

---

## テーブル定義

| 属性名    | 型        | 必須 | 一意 | 説明                                 |
|-----------|-----------|------|------|--------------------------------------|
| id        | int       | ○    | ○    | 主キー（AUTO_INCREMENT）             |
| table_id  | int       | ○    | ○    | テーブルID（論理ID、ユニーク、int型）|
| display_name| varchar | ○    |      | 表示名（日本語等）                   |
| created_at| datetime  | ○    |      | 登録日時                             |
| updated_at| datetime  |      |      | 更新日時                             |

---

## インデックス

| インデックス名 | 種類   | 説明                   | カラム    |
|----------------|--------|------------------------|-----------|
| PRIMARY KEY    | 主キー | 主キー                 | id        |
| UNIQUE         | 一意   | テーブルIDの一意制約   | table_id  |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 一意制約
- `table_id`: テーブルIDの重複禁止

---

## 設計補足
- table_idはint型で管理します。
- display_nameはUI表示や多言語対応に利用できます。
- user_histories等の履歴テーブルで、table_idで管理します。
- idは物理主キー、table_idは論理IDとして利用します。

---
