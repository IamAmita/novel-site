# master_reasons テーブル詳細（理由種別マスタ）

---

## 概要
通報理由・ブロック理由・削除理由など、各種"理由"を一元管理するマスタテーブルです。idは100番以降の数値で管理し、class_idは必要に応じて設定する任意項目です。

---

## テーブル定義

| 属性名        | 型      | 必須 | 一意 | 説明                       |
|---------------|---------|------|------|----------------------------|
| id            | int     | ○    | ○    | 理由ID（主キー、100番以降）|
| class_id      | int     |      |      | 理由種別ID（master_classes.id等、任意）|
| display_name  | varchar | ○    |      | 表示名（日本語等）         |
| created_at    | datetime| ○    |      | 登録日時                   |

---

## インデックス

| インデックス名 | 種類   | 説明           | カラム     |
|----------------|--------|----------------|------------|
| PRIMARY KEY    | 主キー | 主キー         | id         |
| INDEX          | 通常   | 理由種別検索用 | class_id   |

---

## 設計補足
- idは100番以降の数値（例: 100, 101, 250など）で管理し、視認性・管理性を高めます。
- class_idは理由種別を区別したい場合のみ設定する任意項目です（NULL可）。
- display_nameでUIや管理画面に柔軟に表示できます。
- 新しい理由や種別を追加する場合は、本テーブルに1行追加してください。

---

## 運用例
| id  | class_id | display_name | created_at          |
|-----|----------|--------------|---------------------|

---

## 関連テーブル
- master_classes: class_idで参照（理由種別管理、任意）
- reports等: reasonで参照（理由管理）

---

## 備考
- 理由の拡張や表示名変更も容易です。
- idは100番以降の数値で統一し、class_idは必要に応じて設定してください。
