# setting_statuses テーブル詳細

---

## 概要
設定のステータス（状態）を管理するテーブルです。各設定の現在のステータス（完成度、年齢制限など）を記録し、ステータス変更の履歴も保持します。

---

## テーブル定義

| 属性名     | 型       | 必須 | 一意 | 説明                     |
|------------|----------|------|------|--------------------------|
| id         | int      | ○    | ○    | ステータス履歴ID（主キー） |
| setting_id | int      | ○    |      | 設定ID（外部キー）       |
| status_id  | tinyint  | ○    |      | ステータス定義ID（外部キー） |
| created_at | datetime | ○    |      | ステータス変更日時       |

---

## インデックス

| インデックス名           | 種類 | 説明               | カラム                |
|------------------------|------|-------------------|----------------------|
| PRIMARY KEY            | 主キー | ステータス履歴IDの主キー | id                   |
| INDEX                  | 通常 | 設定検索用         | setting_id           |
| INDEX                  | 複合 | 現在のステータス検索用 | setting_id, created_at |
| INDEX                  | 通常 | ステータス検索用   | status_id            |
| INDEX                  | 通常 | 変更日時検索用     | created_at           |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 外部キー制約
- `setting_id` → `settings.id`: 設定テーブルを参照
- `status_id` → `master_statuses.id`: ステータス定義テーブルを参照

### チェック制約
- `status_id`: 有効なステータス定義IDである必要があります

---

## 設計補足

### ステータスID（status_id）
- master_statusesテーブルで定義されたステータスのID
- 設定対象のステータス（target_type=設定対象）を参照
- 完成度、年齢制限などの設定固有のステータスを管理

### 現在のステータス管理
- 各設定の最新のレコードが現在のステータス
- ステータス変更時は新しいレコードを作成
- 履歴として過去のステータスも保持

### 権限制御
- ステータスに応じた権限制御はアプリケーション側で実装
- 設定の表示・編集権限をステータスに基づいて判定

## 関連テーブル

- `settings`: 多対1の関係（設定のステータス管理）
- `master_statuses`: 多対1の関係（ステータス定義）
- `setting_histories`: 1対多の関係（ステータス変更理由の履歴）

---

## 運用上の注意点

1. **ステータス変更**: 変更時は新しいレコードを作成
2. **権限制御**: アプリケーション側でステータスに応じた権限チェックを実施
3. **履歴管理**: ステータス変更の履歴を保持し、透明性を確保
4. **パフォーマンス**: 現在のステータス取得は`setting_id, created_at`の複合インデックスを活用
5. **変更理由**: ステータス変更の理由は`setting_histories`テーブルで管理
6. **データ整合性**: 設定削除時は関連するステータスレコードも削除
