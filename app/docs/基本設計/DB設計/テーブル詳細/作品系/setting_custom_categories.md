# 設定独自カテゴリテーブル（setting_custom_categories）

---

## 概要
設定のユーザー独自カテゴリを管理するテーブル。ユーザーが独自に作成するカテゴリ分類を階層構造で管理し、特定の設定専用のカテゴリを提供する。

---

## テーブル定義

| 属性名               | 型            | 必須 | 一意 | 説明                                         |
|----------------------|---------------|------|------|----------------------------------------------|
| id                   | int           | ○    | ○    | カテゴリID（主キー）                         |
| setting_id           | int           | ○    |      | 設定ID（外部キー）                           |
| name                 | varchar(100)  | ○    |      | カテゴリ名                                   |
| description          | text          |      |      | カテゴリの説明                               |
| parent_id            | int           |      |      | 親カテゴリID（階層構造用）                   |
| parent_category_type | varchar(1)    |      |      | 親カテゴリ種別（0:マスタ, 1:独自, '':未指定可）|
| level                | int           | ○    |      | 階層レベル（0:メイン, 1:サブ）               |
| order_in_parent      | int           | ○    |      | 親カテゴリ内での表示順序                     |
| is_active            | tinyint(1)    | ○    |      | 有効フラグ（0:無効, 1:有効）                 |
| created_at           | datetime      | ○    |      | 作成日時                                     |
| updated_at           | datetime      | ○    |      | 更新日時                                     |

---

## インデックス

| インデックス名           | 種類 | 説明               | カラム                |
|------------------------|------|-------------------|----------------------|
| PRIMARY KEY            | 主キー | カテゴリIDの主キー | id                   |
| INDEX                  | 通常 | 設定検索用         | setting_id           |
| INDEX                  | 通常 | 親カテゴリ検索用   | parent_id            |
| INDEX                  | 通常 | 親カテゴリ種別検索用 | parent_category_type |
| INDEX                  | 通常 | 階層レベル検索用   | level                |
| INDEX                  | 通常 | 有効フラグ検索用   | is_active            |
| INDEX                  | 通常 | 作成日時検索用     | created_at           |
| INDEX                  | 複合 | 設定・親カテゴリ・表示順序検索用 | setting_id, parent_id, order_in_parent |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 外部キー制約
- `setting_id` → `settings.id`
- `parent_id` → `setting_custom_categories.id` (自己参照)

### チェック制約
- `level` >= 0
- `order_in_parent` >= 0
- `is_active` IN (0, 1)
- `parent_category_type` IN ('', '0', '1')

---

## 設計補足

### 親カテゴリ種別（parent_category_type）
- '0': 親カテゴリはマスタカテゴリ（setting_categories）
- '1': 親カテゴリは独自カテゴリ（setting_custom_categories）
- '': ルートカテゴリや特別なケースで未指定も可（空文字）
- サブカテゴリ作成時に親カテゴリの種別を指定しても良い（空文字可）

### ユーザー独自カテゴリ管理
- 各設定専用のユーザー独自カテゴリ分類
- 設定削除時は関連カテゴリも削除
- 設定間でのカテゴリ共有は不可

### 階層構造管理
- `parent_id`と`parent_category_type`、`level`を使用して階層構造を実現
- メインカテゴリ（level = 0）とサブカテゴリ（level = 1）の2階層構造
- 将来的にサブサブカテゴリ（level = 2）への拡張も可能

### 表示順序
- `order_in_parent`で同階層内での表示順序を管理
- カテゴリの並び替えに対応

### 有効フラグ
- `is_active`でカテゴリの有効/無効を管理
- 無効カテゴリは表示・選択不可

---

## 関連テーブル

- `settings`: 多対1の関係（設定の基本情報）
- `setting_categories`: 1対多の関係（マスタカテゴリ適用）
- `setting_details`: 1対多の関係（設定の詳細情報）

---

## 運用上の注意点

1. **親カテゴリ種別の管理**: サブカテゴリ作成時は親カテゴリ種別を指定しても良い（空文字可）
2. **設定専用**: 各設定専用のカテゴリ管理
3. **階層構造**: 親カテゴリの削除時は子カテゴリの処理を考慮
4. **表示順序**: カテゴリの並び替え時の整合性維持
5. **パフォーマンス**: 設定別の階層クエリの最適化
6. **データ整合性**: 設定削除時の関連カテゴリ削除

---

## 注意事項

1. **設定専用**: 各設定専用のカテゴリ管理
2. **階層構造**: `parent_id`と`level`を使用して階層構造を実現
3. **マスタカテゴリとの統合**: マスタカテゴリテーブルとの連携
4. **パフォーマンス**: 設定別の階層クエリの最適化
