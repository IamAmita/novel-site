# 作品系テーブル詳細

---

## 概要
小説投稿サイトの作品系テーブル群。特に設定管理機能に主眼を置いた設計となっており、世界観、キャラクター、アイテムなどの設定を階層構造で管理し、協作者機能や権限管理も含む包括的な設定管理システムを提供する。

---

## テーブル一覧

### 主要テーブル

#### 1. **設定テーブル** (`settings`)
- **概要**: 設定管理機能の中核テーブル
- **特徴**: 
  - 階層構造による設定の整理
  - 詳細な権限管理（閲覧・編集・管理）
  - 協作者機能による共同編集
  - 豊富なメタデータ（重要度、完成度、年齢制限など）
  - 統計・評価機能

#### 2. **設定カテゴリテーブル** (`setting_categories`)
- **概要**: 設定の分類を管理するマスターテーブル
- **特徴**:
  - 階層構造による柔軟な分類
  - システムカテゴリとユーザー作成カテゴリの区別
  - アイコン・カラーによる視覚的な分類

#### 3. **設定タグ関連テーブル** (`setting_tags`)
- **概要**: 設定とタグの多対多関係を管理
- **特徴**:
  - タグによる検索・分類機能
  - 重複防止機能

#### 4. **設定協作者テーブル** (`setting_collaborators`)
- **概要**: 設定の共同編集者を管理
- **特徴**:
  - 3段階の権限レベル（閲覧・編集・管理）
  - 招待→承認フロー
  - 招待メッセージ機能

#### 5. **設定履歴テーブル** (`setting_histories`)
- **概要**: 設定の変更履歴を管理
- **特徴**:
  - 全ての操作の記録
  - 変更前後の値の保持
  - 復元機能のサポート

### 関連テーブル

#### 6. **小説作品テーブル** (`novels`)
- **概要**: 小説作品の基本情報を管理
- **特徴**: 設定との関連付け

#### 7. **章（チャプター）テーブル** (`chapters`)
- **概要**: 作品内の章構成を管理

#### 8. **話（エピソード）テーブル** (`episodes`)
- **概要**: 実際の本文コンテンツを管理

#### 9. **タグテーブル** (`tags`)
- **概要**: タグのマスターデータ

#### 10. **年齢制限テーブル** (`age_limits`)
- **概要**: 年齢制限のマスターデータ

## 設定機能の特徴

### 1. **階層構造管理**
- `parent_id`と`root_id`による柔軟な階層構造
- `path`カラムによる効率的な階層クエリ
- 無限階層のサポート

### 2. **権限管理システム**
- **閲覧権限**: public（全員）、registered（登録ユーザー）、private（作成者のみ）
- **編集権限**: owner（作成者のみ）、collaborators（協作者）、public（全員）
- **協作者権限**: view（閲覧）、edit（編集）、admin（管理）

### 3. **協作者機能**
- 招待→承認フロー
- 権限レベルの細かい制御
- 招待メッセージ機能

### 4. **履歴管理**
- 全ての変更の記録
- 変更前後の値の保持
- 復元機能のサポート

### 5. **メタデータ管理**
- 重要度、完成度、難易度
- 年齢制限、公開状態
- 統計情報（閲覧数、いいね数など）

## 設計方針

### 1. **拡張性**
- JSONカラムによる柔軟なデータ構造
- 階層構造による無限の拡張性
- プラグイン的な機能追加が可能

### 2. **保守性**
- 論理削除によるデータ保護
- 詳細な履歴管理
- 明確な権限分離

### 3. **パフォーマンス**
- 適切なインデックス設計
- 階層クエリの最適化
- 統計情報の事前計算

### 4. **セキュリティ**
- 細かい権限管理
- 操作履歴の記録
- データの整合性保証
