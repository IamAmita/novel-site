# 設定カテゴリテーブル（setting_categories）

---

## 概要
設定に適用するマスタカテゴリを管理するテーブル。マスタカテゴリ（標準分類）を設定に適用し、階層構造で管理する。独自カテゴリは別テーブル（setting_custom_categories）で管理する。

---

## テーブル定義

| 属性名           | 型            | 必須 | 一意 | 説明                           |
|------------------|---------------|------|------|--------------------------------|
| id               | int           | ○    | ○    | カテゴリID（主キー）           |
| setting_id       | int           | ○    |      | 設定ID（外部キー）             |
| category_id      | int           | ○    |      | マスタカテゴリID（外部キー）   |
| parent_id        | int           |      |      | 親カテゴリID（階層構造用）     |
| level            | int           | ○    |      | 階層レベル（0:メイン, 1:サブ） |
| order_in_parent  | int           | ○    |      | 親カテゴリ内での表示順序       |
| is_active        | tinyint(1)    | ○    |      | 有効フラグ（0:無効, 1:有効）   |
| created_at       | datetime      | ○    |      | 作成日時                       |
| updated_at       | datetime      | ○    |      | 更新日時                       |

---

## インデックス

| インデックス名           | 種類 | 説明               | カラム                |
|------------------------|------|-------------------|----------------------|
| PRIMARY KEY            | 主キー | カテゴリIDの主キー | id                   |
| INDEX                  | 通常 | 設定検索用         | setting_id           |
| INDEX                  | 通常 | マスタカテゴリ検索用 | category_id         |
| INDEX                  | 通常 | 親カテゴリ検索用   | parent_id            |
| INDEX                  | 通常 | 階層レベル検索用   | level                |
| INDEX                  | 通常 | 有効フラグ検索用   | is_active            |
| INDEX                  | 通常 | 作成日時検索用     | created_at           |
| INDEX                  | 複合 | 設定・親カテゴリ・表示順序検索用 | setting_id, parent_id, order_in_parent |
| UNIQUE                 | 一意 | 設定・マスタカテゴリの重複防止 | setting_id, category_id |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 外部キー制約
- `setting_id` → `settings.id`
- `category_id` → `master_categories.id`
- `parent_id` → `setting_categories.id` (自己参照)

### チェック制約
- `level` >= 0
- `order_in_parent` >= 0
- `is_active` IN (0, 1)

---

## 設計補足

### マスタカテゴリの適用管理
- マスタカテゴリを設定に適用する際の管理
- 同一設定に同一マスタカテゴリを重複適用不可
- 設定削除時は関連するマスタカテゴリ適用も削除

### 階層構造管理
- `parent_id`と`level`を使用して階層構造を実現
- メインカテゴリ（level = 0）とサブカテゴリ（level = 1）の2階層構造
- 将来的にサブサブカテゴリ（level = 2）への拡張も可能

### 表示順序
- `order_in_parent`で同階層内での表示順序を管理
- カテゴリの並び替えに対応

### 有効フラグ
- `is_active`でカテゴリの有効/無効を管理
- 無効カテゴリは表示・選択不可

---

## 関連テーブル

- `settings`: 多対1の関係（設定の基本情報）
- `master_categories`: 多対1の関係（マスタカテゴリ）
- `setting_custom_categories`: 1対多の関係（独自カテゴリ）
- `setting_details`: 1対多の関係（設定の詳細情報）

---

## 運用上の注意点

1. **マスタカテゴリの適用**: マスタカテゴリの適切な適用管理
2. **階層構造**: 親カテゴリの削除時は子カテゴリの処理を考慮
3. **表示順序**: カテゴリの並び替え時の整合性維持
4. **パフォーマンス**: 設定別の階層クエリの最適化
5. **データ整合性**: 設定削除時の関連カテゴリ削除
6. **マスタカテゴリの整合性**: マスタカテゴリ削除時の処理

---

## 注意事項

1. **マスタカテゴリの適用**: マスタカテゴリの適切な適用管理
2. **階層構造**: `parent_id`と`level`を使用して階層構造を実現
3. **マスタカテゴリの整合性**: マスタカテゴリ削除時の処理を考慮
4. **パフォーマンス**: マスタカテゴリとの結合クエリの最適化
5. **独自カテゴリとの統合**: 独自カテゴリテーブルとの連携
