# 小説タグ中間テーブル（novel_tags）

---

## 概要
小説（novels）とタグ（tags）の多対多関係を管理する中間テーブル。小説に複数のタグを付与し、タグによる検索や分類を実現する。

---

## テーブル定義

| 属性名        | 型            | 必須 | 一意 | 説明                           |
|---------------|---------------|------|------|--------------------------------|
| id            | int           | ○    | ○    | 小説タグID（主キー）           |
| novel_id      | int           | ○    |      | 小説ID（novels.idを参照、NOT NULL） |
| tag_id        | int           | ○    |      | タグID（tags.idを参照、NOT NULL）   |
| delete_flg    | tinyint(1)    | ○    |      | 削除フラグ（0:有効, 1:削除済み） |
| created_at    | datetime      | ○    |      | 作成日時                       |
| updated_at    | datetime      | ○    |      | 更新日時                       |
| deleted_at    | datetime      |      |      | 削除日時                       |

---

## インデックス

| インデックス名           | 種類 | 説明               | カラム                |
|------------------------|------|-------------------|----------------------|
| PRIMARY KEY            | 主キー | 小説タグIDの主キー | id                   |
| INDEX                  | 通常 | 小説ID検索用       | novel_id             |
| INDEX                  | 通常 | タグID検索用       | tag_id               |
| INDEX                  | 通常 | 削除フラグ検索用   | delete_flg           |
| INDEX                  | 通常 | 作成日時検索用     | created_at           |
| INDEX                  | 通常 | 更新日時検索用     | updated_at           |
| INDEX                  | 通常 | 削除日時検索用     | deleted_at           |
| UNIQUE                 | 複合一意 | 小説ID・タグIDの組み合わせ一意 | novel_id, tag_id |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 外部キー制約
- `novel_id` → `novels.id`（NOT NULL）
- `tag_id` → `tags.id`（NOT NULL）

### チェック制約
- `delete_flg` IN (0, 1)

### 一意制約
- `novel_id`, `tag_id`の組み合わせは一意

---

## 設計補足

- **多対多関係**: 小説1件に複数タグ、タグ1件に複数小説を紐付け可能。
- **論理削除**: `delete_flg`で論理削除を実現し、`deleted_at`で削除日時を記録。
- **検索機能**: タグによる小説検索や、タグ一覧の取得が容易。

---

## 関連テーブル

- `novels`: 多対多の関係（小説）
- `tags`: 多対多の関係（タグ）

---

## 運用上の注意点

1. **データ整合性**: 小説・タグの存在確認を徹底
2. **論理削除**: 削除されたタグ付与情報の適切な処理
3. **重複防止**: 同一小説・同一タグの重複登録を防止
4. **削除日時管理**: 削除日時の正確な記録
