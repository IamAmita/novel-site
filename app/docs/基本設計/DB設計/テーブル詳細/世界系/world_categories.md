# 世界カテゴリ関連テーブル（world_categories）

---

## 概要
世界とカテゴリの多対多関係を管理する中間テーブル。統合カテゴリテーブル（categories）を使用し、世界に複数のカテゴリを適用することができる。表示順序は世界ごとに管理する。

---

## テーブル定義

| 属性名               | 型            | 必須 | 一意 | 説明                                     |
|----------------------|---------------|------|------|------------------------------------------|
| id                   | int           | ○    | ○    | 世界カテゴリID（主キー）                 |
| world_id             | int           | ○    |      | 世界ID（外部キー）                       |
| category_id          | int           | ○    |      | カテゴリID（統合カテゴリテーブル）       |
| display_order        | int           | ○    |      | 表示順序（世界ごとの表示順）             |
| created_at           | datetime      | ○    |      | 作成日時                                 |

---

## インデックス

| インデックス名           | 種類 | 説明               | カラム                |
|------------------------|------|-------------------|----------------------|
| PRIMARY KEY            | 主キー | 世界カテゴリIDの主キー | id                   |
| INDEX                  | 通常 | 世界検索用         | world_id             |
| INDEX                  | 通常 | カテゴリ検索用     | category_id          |
| INDEX                  | 通常 | 表示順序検索用     | display_order        |
| INDEX                  | 通常 | 作成日時検索用     | created_at           |
| INDEX                  | 複合 | 世界・表示順序検索用 | world_id, display_order |
| UNIQUE                 | 一意 | 世界・カテゴリIDの重複防止 | world_id, category_id |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 外部キー制約
- `world_id` → `worlds.id`
- `category_id` → `categories.id`

### 一意制約
- `world_id`, `category_id`の組み合わせは一意

### チェック制約
- `display_order` >= 0

---

## 設計補足

### カテゴリの関連付け管理
- 世界とカテゴリの多対多の関係を管理
- 統合カテゴリテーブル（categories）を使用
- 同一世界に同一カテゴリを重複適用不可
- 世界削除時は関連するカテゴリ適用も削除

### 統合カテゴリテーブルの活用
- 運営カテゴリとユーザーカテゴリを統一的に管理
- 作成者種別による権限管理
- 階層構造による柔軟な分類

### 表示順序の管理
- `display_order`で世界ごとのカテゴリ表示順序を管理
- サーバーサイドでの一意制御によるデータ整合性の確保

---

## 関連テーブル

- `worlds`: 多対1の関係（世界の基本情報）
- `categories`: 多対1の関係（統合カテゴリ）
- `world_info`: 1対多の関係（世界の詳細情報）

---

## 運用上の注意点

1. **カテゴリの関連付け**: 統合カテゴリテーブルとの適切な関連付け管理
2. **データ整合性**: 世界削除時の関連カテゴリ削除
3. **カテゴリのアクティブ状態**: 非アクティブカテゴリの処理
4. **パフォーマンス**: 世界別のカテゴリ検索クエリの最適化
5. **権限管理**: カテゴリの作成者種別に応じた権限チェック
6. **表示順序の管理**: 
   - 世界ごとの表示順序の整合性維持
   - カテゴリ追加・削除時の表示順序の調整
   - サーバーサイドでの一意制御によるデータ整合性の確保
7. **物理削除の管理**: 
   - カテゴリ割り当ての削除前の確認処理
   - 関連データの整合性維持

---

## 注意事項

1. **統合カテゴリ**: 運営カテゴリとユーザーカテゴリの統一的な管理
2. **権限管理**: 作成者種別に応じた適切な権限制御
3. **パフォーマンス**: カテゴリ検索の最適化
4. **データ整合性**: カテゴリ削除時の関連レコードの処理
5. **表示順序**: 世界ごとの表示順序管理と整合性維持
6. **物理削除**: カテゴリ割り当ての削除と関連データの整合性管理
