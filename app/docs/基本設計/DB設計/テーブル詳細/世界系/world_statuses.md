# world_statuses テーブル詳細（世界ステータス管理）

---

## 概要
世界（世界観・キャラクター等）のステータス（状態）を管理するテーブルです。世界の完成度（下書き、作成中、完成、アーカイブ）や年齢制限（全年齢、R-15、R-18）などのステータスを履歴として保持します。

---

## テーブル定義

| 属性名           | 型      | 必須 | 一意 | 説明                                 |
|------------------|---------|------|------|--------------------------------------|
| id               | int     | ○    | ○    | ステータス履歴ID（主キー）           |
| world_id         | int     | ○    |      | 世界ID（worlds.idを参照）            |
| status_id        | tinyint | ○    |      | ステータス定義ID（master_statuses.idを参照） |
| status_value     | tinyint | ○    |      | ステータス値（数値コード）           |
| created_at       | datetime| ○    |      | ステータス変更日時                   |
| updated_at       | datetime| ○    |      | 更新日時                             |
| deleted_at       | datetime|      |      | 削除日時                             |
| is_deleted       | tinyint | ○    |      | 削除フラグ（0：有効、1：削除済み、デフォルト：0） |

---

## インデックス

| インデックス名 | 種類   | 説明                   | カラム           |
|----------------|--------|------------------------|------------------|
| PRIMARY KEY    | 主キー | ステータス履歴IDの主キー | id               |
| UNIQUE         | 複合   | 1世界1ステータスの重複防止 | world_id, status_id |
| INDEX          | 通常   | 世界検索用             | world_id         |
| INDEX          | 複合   | 現在のステータス検索用 | world_id, created_at |
| INDEX          | 通常   | ステータス検索用       | status_id        |
| INDEX          | 通常   | 変更日時検索用         | created_at       |
| INDEX          | 通常   | 削除フラグ検索用       | is_deleted       |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 外部キー制約
- `world_id` → `worlds.id`: 世界テーブルを参照
- `status_id` → `master_statuses.id`: ステータス定義テーブルを参照

### ユニーク制約
- `world_id, status_id`: 1世界に同じステータスを重複登録不可

### チェック制約
- `status_id`: 世界用ステータス定義ID（101〜104、201〜203、301〜303）のみ許可
- `status_value`: 1〜255の範囲の数値のみ許可
- `is_deleted`: 0（有効）または1（削除済み）のみ許可、デフォルト値は0

---

## 設計補足

### ステータスID（status_id）
- master_statusesテーブルで定義された世界用ステータスのID
- 完成度：101〜104、年齢制限：201〜203、公開状態：301〜303
- 例：101（draft）、102（in_progress）、201（all_ages）、202（r15）

### ステータス値（status_value）
- システム内部で使用する数値コード
- master_statusesのstatus_valueと同期を保つ
- アプリケーション側での判定に使用
- 1〜255の範囲で管理（tinyintの制限）

### 現在のステータス管理
- 各世界の最新のレコードが現在のステータス
- ステータス変更時は新しいレコードを作成
- 履歴として過去のステータスも保持

### 論理削除
- 論理削除により、参照整合性を保ちながらデータの履歴を保持
- 削除されたレコードは通常の検索から除外
- is_deleted = 0：有効なレコード
- is_deleted = 1：削除済みレコード

## 関連テーブル

- `worlds`: world_idで参照（世界管理）
- `master_statuses`: status_idで参照（ステータス定義）
- `setting_histories`: 世界変更履歴
- `novels`: 関連小説（世界を参照）

---

## 運用上の注意点

1. **ステータス変更**: 変更時は新しいレコードを作成
2. **履歴管理**: ステータス変更の履歴を保持し、透明性を確保
3. **パフォーマンス**: 現在のステータス取得は`world_id, created_at`の複合インデックスを活用
4. **データ整合性**: 世界削除時は関連するステータスレコードも論理削除
5. **論理削除**: 削除されたレコードは通常の検索から除外し、履歴として保持
6. **重複防止**: 複合一意制約により、1世界に同じステータスの重複設定を防止
7. **年齢制限**: 年齢制限変更時の関連作品への影響確認
8. **公開状態**: 公開状態変更時の権限チェック

---

## ステータス変更フロー

### 完成度変更
1. 作成者が世界の完成度を変更
2. 新しいレコードを作成
3. 関連する小説に影響がある場合は通知

### 年齢制限変更
1. 作成者または管理者が年齢制限を変更
2. 新しいレコードを作成
3. 関連する小説の年齢制限も連動更新

### 公開状態変更
1. 作成者が公開状態を変更
2. 新しいレコードを作成
3. 閲覧権限の更新
