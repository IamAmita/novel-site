# follows テーブル詳細

---

## 概要
ユーザー間のフォロー関係を管理するテーブルです。フォローするユーザー、フォローされるユーザー、フォロー日時、論理削除フラグなどを含みます。

---

## テーブル定義

| 属性名         | 型         | 必須 | 一意 | 説明                         |
|----------------|------------|------|------|------------------------------|
| id             | int        | ○    | ○    | フォローID（主キー）         |
| follower_id    | int        | ○    |      | フォローするユーザーID       |
| followed_id    | int        | ○    |      | フォローされるユーザーID     |
| delete_flg     | tinyint    | ○    |      | 論理削除フラグ（0:有効, 1:削除済み） |
| created_at     | datetime   | ○    |      | フォロー日時                 |
| updated_at     | datetime   |      |      | 更新日時（解除・再フォロー時等）     |

---

## インデックス

| インデックス名 | 種類 | 説明 | カラム |
|----------------|------|------|--------|
| PRIMARY KEY | 主キー | フォローIDの主キー | id |
| UNIQUE | 複合一意 | フォロー関係の一意制約 | follower_id, followed_id, delete_flg |
| INDEX | 通常 | フォローするユーザー検索用 | follower_id |
| INDEX | 通常 | フォローされるユーザー検索用 | followed_id |
| INDEX | 通常 | 論理削除フラグ検索用 | delete_flg |
| INDEX | 通常 | フォロー日時検索用 | created_at |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 一意制約
- `follower_id, followed_id, delete_flg`: フォロー関係は論理削除フラグを含めて一意である必要があります

### 外部キー制約
- `follower_id` → `users.id`: フォローするユーザーテーブルを参照
- `followed_id` → `users.id`: フォローされるユーザーテーブルを参照

### チェック制約
- `follower_id` ≠ `followed_id`: 自分をフォローすることはできません
- `delete_flg`: 0または1の値のみ許可（0:有効, 1:削除済み）

---

## 設計補足

### フォローするユーザー（follower_id）
- フォローを実行するユーザー
- 存在するユーザーである必要があります

### フォローされるユーザー（followed_id）
- フォローされるユーザー
- 存在するユーザーである必要があります

### 論理削除フラグ（delete_flg）
- 0:有効、1:削除済みとして管理
- フォロー解除時はdelete_flg=1に更新
- 履歴や監査のため物理削除は行わない

### フォロー日時（created_at）
- フォロー関係が成立した日時
- 履歴追跡のために記録

### 更新日時（updated_at）
- フォロー解除や再フォロー時に更新
- 履歴や監査のために利用

### 相互フォロー
- 相互フォローは2つのレコードで管理
- アプリケーション側で相互フォロー判定を実装

---

## 関連テーブル

- `users`: 多対1の関係（フォローするユーザー）
- `users`: 多対1の関係（フォローされるユーザー）

---

## 運用上の注意点

1. **自己フォロー**: 自分をフォローすることはできません
2. **重複フォロー**: 同じユーザーを複数回フォローすることはできません（delete_flg=0のみ有効）
3. **フォロー解除**: delete_flg=1で論理削除、物理削除は行わない
4. **相互フォロー**: アプリケーション側で判定ロジックを実装
5. **updated_at**: フォロー解除や再フォロー時に更新
