# permissions テーブル詳細

---

## 概要
権限の定義を管理するテーブルです。権限名、対象種別、対象ID、説明などを含みます。

---

## テーブル定義

| 属性名         | 型         | 必須 | 一意 | 説明                                 |
|----------------|------------|------|------|--------------------------------------|
| id             | int        | ○    | ○    | 権限定義ID（主キー）                 |
| name           | varchar    | ○    | ○    | 権限名（例：オーナー、管理者、編集者等）|
| target_type    | varchar    | ○    |      | 権限対象種別（小説・設定・掲示板等） |
| target_id      | int        | ○    |      | 権限対象ID                           |
| description    | text       |      |      | 権限の説明                           |
| created_at     | datetime   | ○    |      | 登録日時                             |
| updated_at     | datetime   |      |      | 更新日時                             |

---

## インデックス

| インデックス名 | 種類 | 説明 | カラム |
|----------------|------|------|--------|
| PRIMARY KEY | 主キー | 権限定義IDの主キー | id |
| UNIQUE | 一意 | 権限名の一意制約 | name |
| INDEX | 通常 | 対象種別検索用 | target_type |
| INDEX | 通常 | 対象ID検索用 | target_id |
| INDEX | 通常 | 登録日時検索用 | created_at |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 一意制約
- `name`: 権限名は一意である必要があります

### 外部キー制約
- なし（このテーブルが参照元）

### チェック制約
- `name`: 空文字列は許可しない
- `target_type`: 'novel', 'setting', 'board'のいずれかである必要があります

---

## 設計補足

### 権限名（name）
- 例：「オーナー」「管理者」「編集者」「閲覧者」など
- システム全体で一意である必要があります

### 対象種別（target_type）
- `novel`: 小説作品
- `setting`: 設定（世界観・キャラ等）
- `board`: 掲示板

### 対象ID（target_id）
- 権限が適用される具体的な対象のID
- 対象種別に応じて適切なテーブルを参照

### 権限の説明（description）
- 権限の詳細な説明
- 何ができるか、何ができないかを明記

---

## 関連テーブル

- `user_permissions`: 1対多の関係（ユーザー権限管理）

---

## 運用上の注意点

1. **権限名**: システム全体で一意である必要があります
2. **対象管理**: 対象が削除された場合の権限処理
3. **権限階層**: 権限の優先順位の管理
4. **監査**: 権限変更の履歴管理
