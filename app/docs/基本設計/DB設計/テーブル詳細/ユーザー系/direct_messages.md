# direct_messages テーブル詳細

---

## 概要
ユーザー間のダイレクトメッセージを管理するテーブルです。送信者、受信者、メッセージ本文、既読状態などを含みます。

---

## テーブル定義

| 属性名         | 型         | 必須 | 一意 | 説明                         |
|----------------|------------|------|------|------------------------------|
| id             | int        | ○    | ○    | メッセージID（主キー）       |
| sender_id      | int        | ○    |      | 送信者ユーザーID             |
| receiver_id    | int        | ○    |      | 受信者ユーザーID             |
| body           | text       | ○    |      | メッセージ本文               |
| is_read        | tinyint    | ○    |      | 既読/未読フラグ（0:未読、1:既読） |
| created_at     | datetime   | ○    |      | 送信日時                     |
| updated_at     | datetime   |      |      | 更新日時                     |
| deleted_at     | datetime   |      |      | 論理削除用                   |

---

## インデックス

| インデックス名 | 種類 | 説明 | カラム |
|----------------|------|------|--------|
| PRIMARY KEY | 主キー | メッセージIDの主キー | id |
| INDEX | 通常 | 送信者検索用 | sender_id |
| INDEX | 通常 | 受信者検索用 | receiver_id |
| INDEX | 通常 | 既読状態検索用 | is_read |
| INDEX | 通常 | 送信日時検索用 | created_at |
| INDEX | 通常 | 論理削除検索用 | deleted_at |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 外部キー制約
- `sender_id` → `users.id`: 送信者ユーザーテーブルを参照
- `receiver_id` → `users.id`: 受信者ユーザーテーブルを参照

### チェック制約
- `sender_id` ≠ `receiver_id`: 自分にメッセージを送信することはできません
- `is_read`: 0または1の値のみ許可

---

## 設計補足

### 送信者（sender_id）
- メッセージを送信したユーザー
- 存在するユーザーである必要があります

### 受信者（receiver_id）
- メッセージを受信するユーザー
- 存在するユーザーである必要があります

### メッセージ本文（body）
- メッセージの内容
- テキスト形式で保存
- HTMLタグ等の特殊文字はエスケープ処理

### 既読/未読フラグ（is_read）
- `1`: 既読
- `0`: 未読
- 受信者がメッセージを開いた時に更新

### 論理削除（deleted_at）
- 送信者・受信者ごとに論理削除フラグを持つ
- 両者削除時のみ物理削除
- 履歴保持のため

---

## 関連テーブル

- `users`: 多対1の関係（送信者）
- `users`: 多対1の関係（受信者）

---

## 運用上の注意点

1. **自己送信**: 自分にメッセージを送信することはできません
2. **既読管理**: 受信者がメッセージを開いた時に既読フラグを更新
3. **削除管理**: 送信者・受信者それぞれが削除可能
4. **プライバシー**: メッセージ内容の適切な管理
