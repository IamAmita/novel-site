# two_factor_auth_codes テーブル詳細

---

## 概要
2段階認証（2FA）で発行される認証コードやバックアップコードの発行・利用履歴を管理するテーブルです。

---

## テーブル定義

| 属性名             | 型        | 必須 | 一意 | 説明                                 |
|--------------------|-----------|------|------|--------------------------------------|
| id                 | int       | ○    | ○    | コードID（主キー）                   |
| two_factor_auth_id | int       | ○    |      | two_factor_auth外部キー              |
| code               | varchar   | ○    |      | コード値（暗号化推奨）               |
| issued_at          | datetime  | ○    |      | 発行日時                             |
| used_at            | datetime  |      |      | 利用日時                             |
| is_active          | tinyint   | ○    |      | 有効/無効フラグ（0:有効, 1:無効）    |
| expired_at         | datetime  |      |      | 失効日時                             |

---

## インデックス

| インデックス名 | 種類 | 説明           | カラム               |
|----------------|------|----------------|----------------------|
| PRIMARY KEY    | 主キー | 主キー         | id                   |
| INDEX          | 通常 | 2FA設定検索用   | two_factor_auth_id   |
| INDEX          | 通常 | コード検索用    | code                 |
| INDEX          | 通常 | 有効/無効検索用 | is_active            |
| INDEX          | 通常 | 発行日時検索用  | issued_at            |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 外部キー制約
- `two_factor_auth_id` → `two_factor_auth.id`: 2FA設定テーブルを参照

### チェック制約
- `is_active`: 0または1の値のみ許可（0:有効, 1:無効）

---

## 設計補足
- コード値（code）は暗号化して保存することを推奨
- バックアップコードや一時的な認証コードも本テーブルで一元管理可能
- is_active=1（無効）は利用済み・失効済み・再発行時の無効化などで利用
- used_atがNULLの場合は未使用、値が入っていれば利用済み
- expired_atで有効期限管理も可能

---

## 関連テーブル
- `two_factor_auth`: 多対1の関係（2FA設定）

---

## 運用上の注意点
- コードの発行・利用履歴を詳細に管理する場合に利用
- セキュリティ上、コード値は必ず暗号化して保存
- is_active=1（無効）の場合、認証に利用不可
