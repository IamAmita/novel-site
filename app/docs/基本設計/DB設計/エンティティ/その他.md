# その他エンティティ詳細

---

## 【設計メモ・方針まとめ】
- ブックマークや拡張用テーブル、APIキー管理などは拡張性・保守性を重視。
- 論理削除（deleted_at）カラムを持たせ、物理削除は原則行わず、必要に応じてアーカイブ。
- 履歴やアクセスログは必要に応じて履歴テーブルで管理。
- セキュリティや認可（APIキー等）は暗号化・有効/無効フラグで管理。

---

## ブックマークエンティティ属性一覧

| 属性名         | 型         | 必須 | 一意 | 説明                                 |
|----------------|------------|------|------|--------------------------------------|
| id             | int        | ○    | ○    | ブックマークID（主キー）             |
| user_id        | int        | ○    |      | ユーザーID（外部キー）               |
| target_type    | varchar    | ○    |      | ブックマーク対象種別                 |
| target_id      | int        | ○    |      | ブックマーク対象ID                   |
| memo           | text       |      |      | メモ                                 |
| created_at     | datetime   | ○    |      | 登録日時                             |

---

## その他拡張用テーブル（例）

### アクセスログエンティティ属性一覧
| 属性名         | 型         | 必須 | 一意 | 説明                                 |
|----------------|------------|------|------|--------------------------------------|
| id             | int        | ○    | ○    | アクセスログID（主キー）             |
| user_id        | int        |      |      | ユーザーID（外部キー）               |
| path           | varchar    | ○    |      | アクセスパス                         |
| method         | varchar    | ○    |      | HTTPメソッド                         |
| status_code    | int        | ○    |      | ステータスコード                     |
| ip_address     | varchar    |      |      | IPアドレス                           |
| user_agent     | varchar    |      |      | 端末情報                             |
| created_at     | datetime   | ○    |      | アクセス日時                         |

### APIキー管理エンティティ属性一覧
| 属性名         | 型         | 必須 | 一意 | 説明                                 |
|----------------|------------|------|------|--------------------------------------|
| id             | int        | ○    | ○    | APIキーID（主キー）                  |
| user_id        | int        | ○    |      | ユーザーID（外部キー）               |
| api_key        | varchar    | ○    | ○    | APIキー                              |
| is_active      | tinyint    | ○    |      | 有効/無効フラグ（0:無効、1:有効）    |
| created_at     | datetime   | ○    |      | 発行日時                             |
