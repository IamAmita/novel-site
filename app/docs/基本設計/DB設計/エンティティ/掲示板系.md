# 掲示板系エンティティ詳細

---

## 【設計メモ・方針まとめ】
- 掲示板・スレッド・投稿・返信は用途ごとに分割し、拡張性・保守性を重視。
- 論理削除（deleted_at）カラムを持たせ、物理削除は原則行わず、必要に応じてアーカイブ。
- タグやピン留め（is_pinned）などの属性で管理機能を拡張。
- 投稿・返信の編集履歴や削除履歴は履歴テーブルで管理。

---

## 掲示板エンティティ属性一覧

| 属性名             | 型         | 必須 | 一意 | 説明                                 |
|--------------------|------------|------|------|--------------------------------------|
| id                 | int        | ○    | ○    | 掲示板ID（主キー）                   |
| title              | varchar    | ○    |      | 掲示板タイトル                       |
| description        | text       |      |      | 掲示板説明                           |
| is_public          | boolean    | ○    |      | 公開/非公開フラグ                    |
| created_at         | datetime   | ○    |      | 作成日時                             |
| updated_at         | datetime   |      |      | 更新日時                             |
| deleted_at         | datetime   |      |      | 論理削除用                           |
