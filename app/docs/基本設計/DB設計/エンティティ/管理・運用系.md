# 管理・運用系エンティティ詳細

---

## 【設計メモ・方針まとめ】
- 管理ログ・権限付与・操作履歴などは履歴種別（type）・操作ユーザーID（operated_by）を必ず記録。
- データ量が多くなるテーブルは定期アーカイブ・自動削除運用を推奨。
- 重要な履歴（セキュリティ関連等）は無期限保存、それ以外は容量や運用方針に応じて削除・アーカイブ。
- 権限・ロールは初期はシンプルに、将来的な拡張を見据えuser_roles/rolesテーブルで柔軟に管理。

---

## 管理ログエンティティ属性一覧

| 属性名         | 型         | 必須 | 一意 | 説明                                 |
|----------------|------------|------|------|--------------------------------------|
| id             | int        | ○    | ○    | ログID（主キー）                     |
| user_id        | int        | ○    |      | 操作者ユーザーID                     |
| action         | varchar    | ○    |      | 操作内容（削除・権限変更等）         |
| target_type    | varchar    | ○    |      | 操作対象種別                         |
| target_id      | int        | ○    |      | 操作対象ID                           |
| reason         | text       |      |      | 操作理由                             |
| created_at     | datetime   | ○    |      | 操作日時                             |
