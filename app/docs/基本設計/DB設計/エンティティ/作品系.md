# 作品系エンティティ詳細

---

## 【設計メモ・方針まとめ】
- 作品・章・話・設定などは細かく分割し、拡張性・保守性を重視した設計。
- 論理削除（deleted_at）カラムを持たせ、物理削除は原則行わず、必要に応じてアーカイブ。
- 編集履歴や削除履歴は履歴テーブルで管理。
- 年齢制限（age_limit）や公開状態（status）は属性で管理。
- タグ・カテゴリは中間テーブルやID参照で柔軟に管理。

## 小説作品エンティティ属性一覧

| 属性名             | 型         | 必須 | 一意 | 説明                                 |
|--------------------|------------|------|------|--------------------------------------|
| id                 | int        | ○    | ○    | 小説ID（主キー）                     |
| user_id            | int        | ○    |      | 投稿者ユーザーID（外部キー）         |
| title              | varchar    | ○    |      | 作品タイトル                         |
| description        | text       | ○    |      | 作品説明                             |
| subtitle           | varchar    |      |      | サブタイトル                         |
| summary            | text       |      |      | あらすじ                             |
| cover_image        | varchar    |      |      | 表紙画像URL                          |
| age_limit          | int        | ○    |      | 年齢制限（0:全年齢, 15: R-15, 18: R-18等）|
| status             | varchar    | ○    |      | 公開状態（公開/非公開/下書き等）     |
| related_setting_id | int        |      |      | 関連設定（世界観）ID（外部キー）     |
| created_at         | datetime   | ○    |      | 作成日時                             |
| updated_at         | datetime   |      |      | 更新日時                             |
| deleted_at         | datetime   |      |      | 論理削除用                           |
