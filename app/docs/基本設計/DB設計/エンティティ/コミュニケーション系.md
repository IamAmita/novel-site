# コミュニケーション系エンティティ詳細

---

## 【設計メモ・方針まとめ】
- コメントは共通テーブル方式（target_type, target_id）で管理し、作品・設定・話など多様な対象に柔軟に対応。
- レビューや通知も、対象ごとにtarget_type/target_idで管理する設計を推奨。
- 論理削除（deleted_at）カラムを持たせ、物理削除は原則行わず、必要に応じてアーカイブ。
- 履歴や編集情報は必要に応じて履歴テーブルで管理。

---

## コメントエンティティ属性一覧

| 属性名             | 型         | 必須 | 一意 | 説明                                 |
|--------------------|------------|------|------|--------------------------------------|
| id                 | int        | ○    | ○    | コメントID（主キー）                 |
| user_id            | int        | ○    |      | 投稿者ユーザーID（外部キー）         |
| target_type        | varchar    | ○    |      | コメント対象種別（小説・設定等）     |
| target_id          | int        | ○    |      | コメント対象ID                       |
| body               | text       | ○    |      | コメント本文                         |
| parent_id          | int        |      |      | 親コメントID（返信用、自己参照）     |
| created_at         | datetime   | ○    |      | 作成日時                             |
| updated_at         | datetime   |      |      | 更新日時                             |
| deleted_at         | datetime   |      |      | 論理削除用                           |

## レビューエンティティ属性一覧

| 属性名             | 型         | 必須 | 一意 | 説明                                 |
|--------------------|------------|------|------|--------------------------------------|

| updated_at         | datetime   |      |      | 更新日時                             |
| deleted_at         | datetime   |      |      | 論理削除用                           |

## 通知エンティティ属性一覧

| 属性名             | 型         | 必須 | 一意 | 説明                                 |
|--------------------|------------|------|------|--------------------------------------|
| id                 | int        | ○    | ○    | 通知ID（主キー）                     |
| user_id            | int        | ○    |      | 通知対象ユーザーID                   |
| type               | varchar    | ○    |      | 通知種別（コメント・いいね等）       |

| created_at         | datetime   | ○    |      | 通知日時                             |
