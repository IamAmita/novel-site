# テーブル一覧

---

## 概要
このドキュメントでは、小説投稿サイトで使用するデータベースのテーブル一覧を管理します。

---

## テーブル一覧

### ユーザー系
| テーブル名             | 説明                                 |
|----------------------|--------------------------------------|
| users                | ユーザー基本情報                     |
| user_profiles        | ユーザープロフィール                 |
| user_statuses        | ユーザー状態履歴                     |
| user_permissions     | ユーザー権限                         |
| user_actions         | ユーザーアクション履歴               |
| two_factor_auth_codes| 二要素認証コード                     |
| two_factor_auth      | 二要素認証設定                       |
| login_histories      | ログイン履歴                         |
| follows              | フォロー情報                         |
| direct_messages      | ダイレクトメッセージ                 |
| blocks               | ブロック情報                         |

### 作品系
| テーブル名             | 説明                                 |
|----------------------|--------------------------------------|
| novels               | 小説の基本情報                       |
| novel_info           | 小説のタイトル・説明など詳細情報      |
| novel_statuses       | 小説の状態履歴                       |
| novel_tags           | 小説とタグの中間テーブル              |
| sections             | 小説の章情報                         |
| section_statuses     | 章の状態履歴                         |
| episodes             | 小説の話（エピソード）情報            |
| episode_statuses     | 話の状態履歴                         |

### コミュニケーション系
| テーブル名             | 説明                                 |
|----------------------|--------------------------------------|
| comments             | コメント                              |
| evaluations          | 評価（Good/Bad等）                   |
| notification_statuses| 通知の状態履歴                       |
| notifications        | 通知                                  |
| reviews              | レビュー                              |
| boards               | 掲示板                                |

### 世界系
| テーブル名             | 説明                                 |
|----------------------|--------------------------------------|
| world_statuses       | 世界の状態履歴                       |
| worlds               | 世界の基本情報                       |
| settings             | 設定（世界観・キャラ等）             |
| setting_fields       | 設定項目フィールド                   |
| world_info           | 世界の詳細情報                       |
| world_categories     | 世界カテゴリ                         |
| world_tags           | 世界タグ                             |

### 汎用系
| テーブル名             | 説明                                 |
|----------------------|--------------------------------------|
| categories           | 汎用カテゴリ                         |
| tags                 | 汎用タグ                             |
| templates            | テンプレート                         |

### マスタ系
| テーブル名             | 説明                                 |
|----------------------|--------------------------------------|
| master_statuses      | ステータス定義                        |
| master_two_factor_methods | 二要素認証方式マスタ             |
| master_tables        | テーブル定義マスタ                   |
| master_reasons       | 理由マスタ                           |
| master_permissions   | 権限定義マスタ                       |
| master_operations    | 操作マスタ                           |
| master_classes       | クラス種別マスタ                     |
| master_actions       | アクション種別マスタ                 |

### 管理系
| テーブル名             | 説明                                 |
|----------------------|--------------------------------------|
| reports              | 通報管理テーブル（不適切行為・内容の通報）|
| operation_histories  | 統合操作履歴テーブル（全テーブルの操作履歴）|
| work_stats           | 作品統計テーブル（閲覧数・評価・ランキング等）|

---

## 詳細
各テーブルの詳細は、テーブル詳細フォルダ内の対応するファイルを参照してください。

---

## 注意点
- NULLは「未設定」を意味する。全体適用や特別な意味には使わない。
