# 画面設計の基本方針

本ドキュメントは、小説投稿サイトの画面設計における基本方針を定義します。

---

## 1. 設計原則

### 1.1 ユーザビリティ重視
- **直感的な操作**: 学習コストを最小限に抑えた操作設計
- **一貫性**: 全画面で統一された操作感・デザイン
- **効率性**: 最小の操作で目的を達成できる設計

### 1.2 レスポンシブデザイン
- **PC**: 1024px以上（メインターゲット）
- **タブレット**: 768px-1023px
- **スマートフォン**: 767px以下

### 1.3 アクセシビリティ
- **キーボード操作**: すべての機能をキーボードで操作可能
- **スクリーンリーダー対応**: 適切なaria属性の設定
- **色覚異常対応**: 色だけでなく形状でも情報を表現

## 2. デザインシステム

### 2.1 カラーパレット
- **プライマリカラー**: #1976D2（青）
- **セカンダリカラー**: #424242（グレー）
- **アクセントカラー**: #FF5722（オレンジ）
- **背景色**: #FAFAFA（ライトグレー）
- **テキスト色**: #212121（ダークグレー）

### 2.2 タイポグラフィ
- **フォントファミリー**: 'Noto Sans JP', sans-serif
- **見出し**: 24px, 20px, 18px, 16px
- **本文**: 14px
- **キャプション**: 12px

### 2.3 コンポーネント
- **ボタン**: プライマリ、セカンダリ、テキストボタン
- **フォーム**: テキスト入力、セレクト、チェックボックス
- **カード**: 情報表示用、アクション用
- **ナビゲーション**: ヘッダー、サイドバー、パンくず

## 3. 画面構成

### 3.1 レイアウト構造
```
┌─────────────────────────────────────┐
│ ヘッダー（ロゴ、ナビ、ユーザーメニュー） │
├─────────────────────────────────────┤
│ メインコンテンツエリア              │
│ ┌─────────────┬───────────────────┐ │
│ │ サイドバー   │ コンテンツエリア   │ │
│ │ （オプション）│                   │ │
│ └─────────────┴───────────────────┘ │
└─────────────────────────────────────┘
```

### 3.2 共通要素
- **ヘッダー**: ロゴ、ナビゲーション、ユーザーメニュー
- **フッター**: リンク、著作権情報
- **サイドバー**: フィルタ、カテゴリ、関連情報
- **パンくず**: 現在位置の表示

## 4. 画面遷移設計

### 4.1 遷移パターン
- **モーダル**: 軽量な操作（確認、編集）
- **ページ遷移**: 重い操作、新しいコンテキスト
- **タブ切り替え**: 関連する情報の表示
- **アコーディオン**: 詳細情報の展開

### 4.2 ローディング状態
- **スケルトンローディング**: 初期表示時
- **プログレスバー**: 処理時間が予測可能な場合
- **スピナー**: 短時間の処理

## 5. エラーハンドリング

### 5.1 エラー表示
- **バリデーションエラー**: フォーム内にインライン表示
- **APIエラー**: トースト通知またはエラー画面
- **ネットワークエラー**: 再接続ボタン付きエラー画面

### 5.2 フォールバック
- **画像読み込み失敗**: プレースホルダー画像
- **データ取得失敗**: 空状態の表示
- **機能利用不可**: 代替手段の提示

## 6. パフォーマンス考慮

### 6.1 読み込み最適化
- **遅延読み込み**: 画像、コンポーネント
- **仮想スクロール**: 大量データの表示
- **キャッシュ**: 頻繁に使用されるデータ

### 6.2 インタラクション最適化
- **デバウンス**: 検索入力
- **スロットリング**: スクロールイベント
- **最適化されたアニメーション**: 60fps維持
