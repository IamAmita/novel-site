# リソース一覧

本ドキュメントは、小説投稿サイトのAPI設計における主要リソース（エンティティ）をまとめたものです。

---

## ユーザー系
- **users**：ユーザーアカウント情報
- **user_profiles**：ユーザープロフィール
- **user_statuses**：ユーザー状態（アクティブ/退会など）
- **user_permissions**：ユーザーごとの権限情報
- **login_histories**：ログイン履歴
- **blocks**：ブロック情報
- **follows**：フォロー関係
- **direct_messages**：ダイレクトメッセージ
- **two_factor_auth**：二要素認証設定
- **two_factor_auth_codes**：二要素認証コード
- **user_actions**：ユーザーの各種アクション履歴

## 作品系
- **novels**：小説（作品）本体
- **novel_info**：小説の詳細情報
- **novel_statuses**：小説の公開状態など
- **novel_tags**：小説に紐づくタグ
- **episodes**：小説のエピソード（章）
- **sections**：エピソード内の話
- **episode_statuses**：エピソードの状態
- **section_statuses**：話の状態

## 設定・世界観系
- **settings**：設定（世界観・用語など）
- **setting_fields**：設定項目の詳細
- **worlds**：世界観情報
- **world_info**：世界観の詳細
- **world_statuses**：世界観の状態
- **world_tags**：世界観のタグ
- **world_categories**：世界観のカテゴリ

## コミュニケーション系
- **comments**：コメント
- **boards**：掲示板
- **reviews**：レビュー
- **evaluations**：評価
- **notifications**：通知
- **notification_statuses**：通知の既読/未読状態

## 管理・マスタ系
- **master_classes**：マスタ分類
- **master_tables**：マスタテーブル情報
- **master_statuses**：マスタ状態
- **master_permissions**：権限マスタ
- **master_operations**：操作マスタ
- **master_actions**：アクションマスタ
- **master_reasons**：理由マスタ
- **operation_histories**：操作履歴
- **reports**：通報・レポート
- **work_stats**：作品統計

## 汎用系
- **categories**：カテゴリ
- **tags**：タグ
- **templates**：テンプレート

---

※今後の設計・実装に応じて追加・修正する場合があります。
