## 4. 技術選定（決定済み）

### 4.1 採用技術スタック
- **フロントエンド**: Vue.js 3 + TypeScript, Vuetify 3, Pinia, Vue Router 4, Axios, Vite
- **バックエンド**: Python 3.11, Django 4, Django REST Framework, JWT, Django Admin, Celery + Redis
- **データベース**: PostgreSQL 15（Full-Text Search, JSONB）
- **インフラ・運用**: Docker, Docker Compose, AWS（ECS, RDS, S3, CloudFront, CloudWatch）, GitHub Actions, Git + GitHub

### 4.2 技術選定理由
- 学習コストと拡張性のバランス
- 日本語ドキュメントやコミュニティの充実
- AWS経験の活用、将来の拡張性・運用性
