## 1. なぜいま整理するか

`functional-scope.md` は **世界観 → 設定 / 作品** の階層に更新済みだが、`core-entities.md` は旧モデル（**小説 → 設定**、読者中心）のまま。

エンティティを整理せずに実装に進むと、DB 設計・API・画面すべてで手戻りが発生する。
