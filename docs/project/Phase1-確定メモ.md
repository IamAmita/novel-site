## 1. Phase 1 のゴール

### 1.1 一言で

設定管理を自由かつ詳細に行い、それを見ながら執筆できる状態。

### 1.2 最小成功

設定管理ができる。（快適さはリリース後の改善で追求する）

### 1.3 完了条件（チェックリスト）

- [ ] 設定管理が自由かつ詳細にできる
- [ ] 設定を執筆画面から参照できる
- [ ] 設定の作成・編集・削除・一覧・検索ができる
- [ ] World 配下で作品（章・話・本文）を執筆できる
- [ ] 設定・作品・本文を検索できる
- [ ] 変更履歴・編集ログが記録・確認できる

### 1.4 Phase 1 の成功基準

プロダクト定義 §8 を Phase 1 スコープに限定した状態：

- 自分が使って、設定管理ができる
- 設定を見ながら執筆できる

### 1.5 Phase 1 に含めないこと（確定）

- 共同創作
- 一般公開（**公開という概念自体がない**）
- コメント・評価・通知・掲示板
- ルビ・縦書き（主機能として）
- タグ・カテゴリ
- 管理者機能

## 2. ドメイン構造（Phase 1）

プロダクト定義・既存ドキュメントから変更。Phase 1 の前提モデル。

```
作者（ペンネーム単位）
└── World（世界観）
    ├── Setting（設定）  ← World に紐づく
    └── 作品（小説）
        └── 章（Chapter）
            └── 話（Episode）・本文
```

| 概念 | Phase 1 での位置づけ |
|------|---------------------|
| World | 最上位の創作単位。作品の親 |
| Setting | World に紐づく。種類は詳細に定義 |
| 作品 | World の下位概念 |
| 公開状態 | **存在しない**（非公開固定の前段階） |

## 4. 設定管理（Phase 1）— コア

### 4.1 概念モデル

| 概念 | Phase 1 | 説明 |
|------|---------|------|
| World（世界観） | **必須** | 作品の上位 |
| Setting（設定） | **必須** | 種類は詳細に（キャラ / 世界 / 物品 / 概念 等）。**World 単位** または **Novel（作品）単位** のいずれかに紐づく（排他）。World 単位は World 内の全作品から参照可、Novel 単位はその作品専用 |
| 設定テンプレート（種類定義） | **必須** | 設定の種類をテンプレートとして定義。Setting と同じく World 単位／Novel 単位のいずれかで作成可能。テンプレートの雛形項目＋Setting個別の追加項目のハイブリッド方式 |
| 設定フィールド（カスタム項目） | **必須** | 設定ごとに自由に項目を追加（テンプレート由来＋個別追加） |
| 設定間の関係性 | **必須** | 「A の師匠は B」等。方向性あり、ラベルはシステム共通マスタ＋World固有ラベルの両方から選択 |
| 関係性の視覚化 | **任意** | 一旦不要。余力があれば実装 |
| 執筆画面からの設定参照 | **必須** | 本文中のリンク記法（例 `[[設定名]]`）から自動生成＋サイドパネル等からの手動追加の両対応 |
| 設定の公開範囲 | 非公開固定 | 自分だけが閲覧 |

> エンティティレベルの詳細（属性・関係性の正確な定義）は [docs/domain/core-entities.md](../domain/core-entities.md)、[docs/domain/entity-relationships.md](../domain/entity-relationships.md) を正とする（2026-07-21 確定）。

### 4.2 必須操作

1. **作成**
2. **編集**
3. **削除**
4. **一覧**
5. **検索**

### 4.3 Phase 1 で後回しにする設定機能

現時点では該当なし（今後追加の可能性あり）。

### 4.4 設定の閲覧 UX

- 設定の一覧・詳細画面は **必要**
- 詳細な画面構成は **後日詰める**
