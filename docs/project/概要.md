# プロジェクト概要

## プロジェクト名
小説投稿サイト - 設定管理・執筆支援プラットフォーム

## 目的
設定管理を自由かつ詳細に行い、それを見ながら執筆できる小説投稿サイトを実装する。

## 基本コンセプト
- **設定管理と執筆の両立**: World（世界観）・Setting（設定）を軸にした創作支援
- **段階的なスコープ拡張**: Phase 1（設定管理と執筆）→ Phase 2（共同制作）→ Phase 3（一般公開）
- **実用的学習**: 実際の開発現場で活用可能な技術習得

## 対象技術

### プログラミング言語
- **Python** - Django + Django REST Framework によるバックエンド実装
- **TypeScript** - React によるフロントエンド実装

### データベース
- **PostgreSQL** - リレーショナルDBによるデータ管理
- **Redis** - キャッシュ

## 学習目標
- Django の設計思想と開発パターンの理解
- Django REST Framework による API 開発
- React + TypeScript による SPA 開発
- 要件整理・ドメインモデリングの実践

## 開発方針
- **段階的実装**: Phase 1（設定管理・執筆）を最優先で完成させる
- **要件駆動**: [Phase1-確定メモ](./Phase1-確定メモ.md)・[todo.md](../../todo.md) の決定事項に従って実装する（詳細な要件・設計ドキュメントは決定事項を詰めてから作成する）
- **実用性重視**: 実際の開発現場に適用可能な設計
