## 1. Phase 1 確定メモとは

プロダクト定義では Phase 1 の**大枠**が決まっている。本メモでは次を具体化する。

- Phase 1 で**何を作り、何を作らないか**（機能の粒度）
- Phase 1 **完了**と言える状態（成功基準）
- 設定管理の**最小構成**（World / Setting / 関係性 等）
- 検索など**機能ごとの Phase 判断**
- **実装の優先順位**（何から手を付けるか）

### プロダクト定義から引き継いだ Phase 1 一覧

| 領域 | プロダクト定義での位置づけ |
|------|---------------------------|
| 設定管理 | Phase 1 必須（主眼） |
| 小説本文・章・話 | Phase 1 必須 |
| 自分向け閲覧 | Phase 1 必須 |
| 縦書き・ルビ | Phase 1 必須 |
| ユーザー管理 | 登録即作者 |
| 共同創作 | **Phase 2** |
| 一般向け公開 | **Phase 3** |
| 検索 | 機能ごとに判断 |

## 2. 決め方（推奨手順）

```
Step 1  §A ゴール・完了条件を決める
Step 2  §B ユーザー管理（最小限）を決める
Step 3  §C 設定管理を詰める          ← 最重要・時間をかける
Step 4  §D 作品・執筆を決める
Step 5  §E 閲覧・表示を決める
Step 6  §F 検索を機能別に判断
Step 7  §G Phase 1 除外を再確認
Step 8  §H 実装優先順位を決める
Step 9  §3 ひな形に転記 → Phase1-確定メモ.md として保存
```

**進め方**: ガイド付き質問に箇条書きで答える → ひな形に転記 → `functional-scope.md` を更新。
