## ディレクトリ構成

```
docs/
├── project/          # プロジェクト方針・意思決定記録
├── business/         # 機能要件（functional-scope.md、整理完了）
├── assets/           # 共通アセット（画像等）
└── archive/          # 過去の要件定義・基本設計資料（参照用）
```

### project/ - プロジェクト方針
プロジェクトの基本情報・目的・意思決定の記録

- **概要.md**: プロジェクトの基本情報・目的・対象技術
- **プロダクト定義.md**: サイトの価値提案・提供機能
- **Phase1-確定メモ.md**: Phase 1 のスコープ・ドメイン構造の確定事項（現時点の**正本**）
- **技術選定方針.md**: 技術選定理由・学習目標・期待効果
- 検討記録系ガイド（`*-ガイド.md`）: 各方針を確定させた際のQ&A記録（履歴）

### archive/ - アーカイブ
過去のドキュメント・詳細設計資料を保管（参照のみ、現行設計とは不整合な場合あり）

- **基本設計/**: 詳細なDB設計・API設計・画面設計（旧版）
- **要件定義/**: 初期要件定義・機能要件定義（旧版）
- **python-django-初期実装/**: 2026-05-25方針転換以前の python-django 要件定義書・設計書（Novel中心モデル、現行設計と不整合）
- **開発フロー.md**: 初期開発フロー

---

**技術依存の設計（API・DB・Docker等）は `implementations/python-django/` 側で独自管理する。**
