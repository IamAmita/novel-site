# master_statuses テーブル詳細（状態種別マスタ）

---

## 概要
各種エンティティの状態（例：未読・既読・重要・緊急・有効・無効など）を一元管理するマスタテーブルです。通知の状態管理（notification_statusesテーブル）にも利用されます。

---

## テーブル定義

| 属性名        | 型      | 必須 | 一意 | 説明                       |
|---------------|---------|------|------|----------------------------|
| id            | int     | ○    | ○    | 状態ID（主キー、100〜999の3桁で運用） |
| display_name  | varchar | ○    |      | 表示名（日本語等）         |
| description   | varchar |      |      | 状態の説明                 |
| created_at    | datetime| ○    |      | 登録日時                   |

---

## インデックス

| インデックス名 | 種類   | 説明           | カラム     |
|----------------|--------|----------------|------------|
| PRIMARY KEY    | 主キー | 主キー         | id         |

---

## 設計補足
- 各種エンティティの状態（通知の未読・既読・重要・緊急、ユーザーの有効・無効など）を一元管理します。
- notification_statusesテーブルから参照され、通知の状態管理にも利用されます。
- display_nameやdescriptionでUIや管理画面に柔軟に表示できます。
- 新しい状態種別を追加する場合は、本テーブルに1行追加してください。
- **idは100〜999の3桁で運用します。**

---

## 関連テーブル
- notification_statuses: status_idで参照（通知状態管理）
- その他、各種状態管理テーブル

---

## 備考
- 状態IDは一意に管理し、用途に応じて拡張可能です。
- **idは100〜999の範囲で運用してください。**
- 通知の状態管理にも活用できます。
