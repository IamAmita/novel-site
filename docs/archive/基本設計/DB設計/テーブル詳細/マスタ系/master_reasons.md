# master_reasons テーブル詳細（理由マスタ）

---

## 概要
各種処理の理由（例：ログイン失敗理由など）を一元管理するマスタテーブルです。

---

## テーブル定義

| 属性名      | 型      | 必須 | 一意 | 説明                   |
|-------------|---------|------|------|------------------------|
| id          | int     | ○    | ○    | 理由ID（主キー）       |
| code        | varchar | ○    | ○    | 理由コード             |
| name        | varchar | ○    |      | 理由名（日本語等）     |
| description | varchar |      |      | 詳細説明               |
| created_at  | datetime| ○    |      | 登録日時               |

---

## インデックス

| インデックス名 | 種類 | 説明           | カラム   |
|----------------|------|----------------|----------|
| PRIMARY KEY    | 主キー | 主キー         | id       |
| UNIQUE         | 一意   | コード一意制約 | code     |

---

## サンプルデータ

| id | code         | name                | description           |
|----|-------------|---------------------|-----------------------|
| 1  | PW_ERROR    | パスワード誤り      | パスワードが間違い   |
| 2  | ACCOUNT_OFF | アカウント無効      | アカウントが無効     |
| 3  | 2FA_FAIL    | 2FA認証失敗         | 2段階認証失敗        |
| 4  | LOCKED      | アカウントロック     | ログイン試行回数超過 |

---

## 関連テーブル
- master_classes: class_idで参照（理由種別管理、任意）
- reports等: reasonで参照（理由管理）

---

## 備考
- 理由の拡張や表示名変更も容易です。
- idは100番以降の数値で統一し、class_idは必要に応じて設定してください。
