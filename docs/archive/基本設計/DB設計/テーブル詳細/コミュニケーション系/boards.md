# boards テーブル詳細（掲示板系ひな形）

---

## 概要
掲示板機能に関するテーブルのひな形です。スレッド（掲示板本体）を管理します。

---

## テーブル定義（スレッドテーブル）

| 属性名      | 型      | 必須 | 一意 | 説明               |
|-------------|---------|------|------|--------------------|
| id          | int     | ○    | ○    | スレッドID（主キー）|
| title       | varchar | ○    |      | スレッドタイトル   |
| user_id     | int     | ○    |      | 作成ユーザーID     |
| created_at  | datetime| ○    |      | 作成日時           |
| updated_at  | datetime|      |      | 更新日時           |
| delete_flg  | tinyint | ○    |      | 論理削除フラグ     |

---

## インデックス

- 主キー（id）
- ユーザーID検索用（user_id）
- 論理削除フラグ検索用（delete_flg）
- 作成日時検索用（created_at）

---

## 制約条件

- 主キー制約：idは自動採番
- 外部キー制約：user_idはusersを参照
- チェック制約：delete_flgは0または1

---

## 設計補足

- スレッド（掲示板本体）は論理削除で管理
- コメントや返信機能を追加する場合は別テーブルで管理

---

## 関連テーブル

- users: 多対1の関係（作成ユーザー）

---

## 運用上の注意点

- 論理削除で履歴を保持
- スパム・荒らし対策のための監視
- スレッド内容の適切な管理
