# 世界テーブル（worlds）

---

## 概要
小説投稿サイトの世界管理機能の基本情報を管理するテーブル。世界の詳細情報は`world_info`テーブルで管理し、パフォーマンスと拡張性を向上させる。

---

## テーブル定義

| 属性名        | 型            | 必須 | 一意 | 説明                           |
|---------------|---------------|------|------|--------------------------------|
| id            | int           | ○    | ○    | 世界ID（主キー）               |
| user_id       | int           | ○    |      | 作成者ユーザーID（users.id）   |
| publish_flg   | tinyint(1)    | ○    |      | 公開フラグ（0:非公開, 1:公開） |
| delete_flg    | tinyint(1)    | ○    |      | 削除フラグ（0:有効, 1:削除済み） |
| created_at    | datetime      | ○    |      | 作成日時                       |
| updated_at    | datetime      | ○    |      | 更新日時                       |
| deleted_at    | datetime      |      |      | 削除日時                       |

---

## インデックス

| インデックス名           | 種類 | 説明               | カラム                |
|------------------------|------|-------------------|----------------------|
| PRIMARY KEY            | 主キー | 世界IDの主キー     | id                   |
| INDEX                  | 通常 | 作成者検索用       | user_id              |
| INDEX                  | 通常 | 公開状態検索用     | publish_flg          |
| INDEX                  | 通常 | 削除フラグ検索用   | delete_flg           |
| INDEX                  | 通常 | 作成日時検索用     | created_at           |
| INDEX                  | 通常 | 更新日時検索用     | updated_at           |
| INDEX                  | 通常 | 削除日時検索用     | deleted_at           |
| INDEX                  | 複合 | ユーザー・公開状態検索用 | user_id, publish_flg |
| INDEX                  | 複合 | ユーザー・削除フラグ検索用 | user_id, delete_flg |

---

## 制約条件

### 主キー制約
- `id`: 自動採番（AUTO_INCREMENT）

### 外部キー制約
- `user_id` → `users.id`

### チェック制約
- `publish_flg` IN (0, 1)
- `delete_flg` IN (0, 1)

---

## 設計補足

### データ分離の目的
- **パフォーマンス向上**: 一覧表示時は基本情報のみ取得
- **拡張性**: 詳細情報の柔軟な追加が可能
- **権限管理**: 基本情報と詳細情報で異なる権限設定

### 1対1の関係
- 各世界は必ず1つの詳細情報を持つ
- 世界削除時は詳細情報も削除
- 世界作成時は詳細情報も同時作成

### 基本情報管理
- 作成者、公開状態、日時などの基本情報
- 軽量で高速な検索・一覧表示
- 権限管理の基本単位

### 論理削除
- `delete_flg`で論理削除を実現
- `deleted_at`で削除日時を記録
- 削除された世界は通常の検索から除外

---

## 関連テーブル

- `world_info`: 1対1の関係（世界の詳細情報）
- `world_tags`: 多対多の関係（世界タグ）
- `setting_collaborators`: 1対多の関係（世界協作者）
- `setting_histories`: 1対多の関係（世界変更履歴）
- `world_statuses`: 1対多の関係（世界ステータス）
- `user_permissions`: 多対多の関係（権限管理）
- `work_stats`: 1対1の関係（統計情報）
- `users`: 多対1の関係（作成者）

---

## 運用上の注意点

1. **データ整合性**: 世界作成時は必ず詳細情報も作成
2. **権限管理**: 権限の変更時は`user_permissions`テーブルで管理
3. **統計管理**: 統計情報の更新は`work_stats`テーブルで管理
4. **ステータス管理**: ステータス情報の更新は`world_statuses`テーブルで管理
5. **パフォーマンス**: ユーザー・公開状態による効率的な検索
6. **データ整合性**: 関連世界・作品の存在確認
7. **論理削除**: 削除された世界の適切な処理
8. **削除日時管理**: 削除日時の正確な記録
