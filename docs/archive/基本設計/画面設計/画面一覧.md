# 画面一覧・画面遷移図

本ドキュメントは、小説投稿サイトの画面一覧と画面遷移を定義します。

---

## 1. 画面一覧

## 2. 画面遷移図

### 2.1 メインフロー

```
トップページ (/)
├── ログイン (/login)
│   ├── 新規登録 (/register)
│   └── パスワードリセット (/reset-password)
├── 作品一覧 (/novels)
│   ├── 作品詳細 (/novels/{novel_id})
│   │   ├── 作品編集 (/novels/{novel_id}/edit)
│   │   ├── 章一覧 (/novels/{novel_id}/episodes)
│   │   │   ├── 章詳細 (/novels/{novel_id}/episodes/{episode_id})
│   │   │   │   ├── 章編集 (/novels/{novel_id}/episodes/{episode_id}/edit)
│   │   │   │   └── 話一覧 (/novels/{novel_id}/episodes/{episode_id}/sections)
│   │   │   │       ├── 話詳細 (/novels/{novel_id}/episodes/{episode_id}/sections/{section_id})
│   │   │   │       └── 話編集 (/novels/{novel_id}/episodes/{episode_id}/sections/{section_id}/edit)
│   │   │   └── 章作成 (/novels/{novel_id}/episodes/create)
│   │   └── 章作成 (/novels/{novel_id}/episodes/create)
│   └── 作品作成 (/novels/create)
├── 設定一覧 (/settings)
│   ├── 設定詳細 (/settings/{setting_id})
│   │   └── 設定編集 (/settings/{setting_id}/edit)
│   └── 設定作成 (/settings/create)
├── 検索結果 (/search)
└── ユーザープロフィール (/profile)
```

### 2.2 認証フロー

```
未認証ユーザー
├── トップページ (/)
├── 作品一覧 (/novels) [閲覧のみ]
├── 作品詳細 (/novels/{novel_id}) [閲覧のみ]
├── ログイン (/login)
│   └── 新規登録 (/register)
└── パスワードリセット (/reset-password)

認証済みユーザー
├── トップページ (/)
├── 作品一覧 (/novels)
├── 作品作成 (/novels/create)
├── 設定一覧 (/settings)
├── 設定作成 (/settings/create)
├── ユーザープロフィール (/profile)
└── ログアウト
```

### 2.3 作品作成フロー

```
作品一覧 (/novels)
└── 作品作成 (/novels/create)
    └── 作品詳細 (/novels/{novel_id})
        ├── 章作成 (/novels/{novel_id}/episodes/create)
        │   └── 章詳細 (/novels/{novel_id}/episodes/{episode_id})
        │       └── 話作成 (/novels/{novel_id}/episodes/{episode_id}/sections/create)
        │           └── 話詳細 (/novels/{novel_id}/episodes/{episode_id}/sections/{section_id})
        └── 作品編集 (/novels/{novel_id}/edit)
```

## 3. 画面設計の優先順位

### 3.1 フェーズ1（基本機能）
**高優先度画面**:
- トップページ、ログイン、新規登録
- 作品一覧、作品詳細、作品作成・編集
- 章一覧、章詳細、章作成・編集
- 話一覧、話詳細、話作成・編集
- 設定一覧、設定詳細、設定作成・編集
- ユーザープロフィール

### 3.2 フェーズ2（コミュニケーション機能）
**中優先度画面**:
- 検索結果、タグ一覧、カテゴリ一覧
- コメント一覧、フォロー一覧
- ダイレクトメッセージ
- 掲示板一覧、掲示板詳細、スレッド詳細

### 3.3 フェーズ3（高度な機能）
**低優先度画面**:
- 管理画面関連
- 世界設定関連
- 高度な検索・フィルタ機能
