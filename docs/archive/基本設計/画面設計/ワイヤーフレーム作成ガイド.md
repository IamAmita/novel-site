# ワイヤーフレーム作成ガイド

本ドキュメントは、小説投稿サイトのワイヤーフレーム作成におけるガイドラインを定義します。

---

## 1. ワイヤーフレーム作成の目的

### 1.1 設計の可視化
- **レイアウトの確認**: 画面の構成要素の配置を確認
- **情報設計の検証**: 情報の階層・優先度を検証
- **ユーザビリティの向上**: 操作の流れを最適化

### 1.2 関係者との共有
- **開発チーム**: 実装の指針として活用
- **ステークホルダー**: 機能の理解促進
- **ユーザー**: ユーザビリティテストの素材

## 2. ワイヤーフレーム作成の流れ

### 2.1 準備段階

#### Step 1: 要件の整理
```
1. 機能要件の確認
   - 画面で実現すべき機能
   - ユーザーの目的
   - 制約条件

2. データ要件の確認
   - 表示するデータ項目
   - 入力するデータ項目
   - データの関係性

3. ユーザー要件の確認
   - ターゲットユーザー
   - 使用環境
   - 操作パターン
```

#### Step 2: 参考資料の収集
```
1. 競合サイトの分析
   - 類似機能の実装方法
   - UI/UXパターンの調査
   - 改善点の特定

2. デザインシステムの確認
   - カラーパレット
   - タイポグラフィ
   - コンポーネント仕様

3. 技術制約の確認
   - 使用技術の制約
   - パフォーマンス要件
   - ブラウザ対応
```

### 2.2 作成段階

#### Step 1: ラフスケッチ
```
1. 手書きでのアイデア出し
   - 複数のレイアウト案
   - 要素の配置案
   - 操作フロー案

2. チームでの検討
   - アイデアの共有
   - 改善点の議論
   - 方向性の決定
```

#### Step 2: デジタルワイヤーフレーム
```
1. 基本レイアウトの作成
   - グリッドシステムの適用
   - ヘッダー・フッターの配置
   - メインコンテンツエリアの設定

2. 要素の配置
   - ナビゲーション要素
   - コンテンツ要素
   - アクション要素

3. 詳細の追加
   - テキスト・ラベルの配置
   - アイコン・ボタンの配置
   - フォーム要素の配置
```

#### Step 3: プロトタイプ作成
```
1. インタラクションの追加
   - ボタンクリック
   - フォーム送信
   - 画面遷移

2. 状態の表現
   - ローディング状態
   - エラー状態
   - 成功状態

3. レスポンシブ対応
   - ブレークポイントの設定
   - 要素の再配置
   - 表示・非表示の制御
```

## 3. ワイヤーフレーム作成のポイント

### 3.1 レイアウト設計

#### 情報の階層化
```
1. 視覚的階層の設定
   - 重要度に応じたサイズ・色の使い分け
   - グループ化による情報の整理
   - 空白の効果的な活用

2. 視線の流れの設計
   - F字パターンの活用
   - Z字パターンの活用
   - 自然な視線の流れの作成
```

#### レスポンシブ対応
```
1. ブレークポイントの設定
   - PC: 1024px以上
   - タブレット: 768px-1023px
   - スマートフォン: 767px以下

2. 要素の再配置
   - サイドバーの表示・非表示
   - グリッドレイアウトの変更
   - ナビゲーションの変更
```

### 3.2 ユーザビリティ設計

#### 操作の直感性
```
1. 標準的なUIパターンの活用
   - ボタンの配置・サイズ
   - フォームの構成
   - ナビゲーションの構造

2. フィードバックの設計
   - 操作結果の表示
   - エラーメッセージの表示
   - ローディング状態の表示
```

#### アクセシビリティ
```
1. キーボード操作の対応
   - Tabキーでの移動
   - Enterキーでの実行
   - ショートカットキーの設定

2. スクリーンリーダー対応
   - 適切なラベルの設定
   - aria属性の設定
   - 意味のあるHTML構造
```

## 4. 具体的な画面例

### 4.1 トップページ

#### レイアウト構成
```
┌─────────────────────────────────────┐
│ ヘッダー                            │
│ [ロゴ] [検索] [ログイン] [新規登録]   │
├─────────────────────────────────────┤
│ メインコンテンツ                    │
│ ┌─────────────┬───────────────────┐ │
│ │ サイドバー   │ 新着作品一覧       │ │
│ │ - カテゴリ   │ [作品カード]       │ │
│ │ - タグ       │ [作品カード]       │ │
│ │ - 人気作品   │ [作品カード]       │ │
│ └─────────────┴───────────────────┘ │
└─────────────────────────────────────┘
```

#### 主要要素
- **ヘッダー**: ロゴ、検索ボックス、認証ボタン
- **サイドバー**: カテゴリ、タグ、人気作品
- **メインエリア**: 新着作品一覧、おすすめ作品
- **フッター**: リンク、著作権情報

### 4.2 作品詳細ページ

#### レイアウト構成
```
┌─────────────────────────────────────┐
│ ヘッダー                            │
├─────────────────────────────────────┤
│ 作品情報                            │
│ [タイトル] [作者名] [概要] [タグ]    │
│ [いいね] [ブックマーク] [編集]       │
├─────────────────────────────────────┤
│ 章一覧                              │
│ ┌─────────────────────────────────┐ │
│ │ [章1] [章2] [章3] [章作成]       │ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

#### 主要要素
- **作品情報**: タイトル、作者、概要、タグ
- **アクションボタン**: いいね、ブックマーク、編集
- **章一覧**: 章のリスト、章作成ボタン
- **関連情報**: コメント、評価

#### レイアウト構成
```

│ │ タイトル: [入力欄]               │ │
```

- **プレビュー**: リアルタイムプレビュー
- **アクションボタン**: 保存、キャンセル、下書き保存

## 5. ツール・テンプレート

### 5.1 推奨ツール

#### ワイヤーフレーム作成ツール
- **Figma**: 無料版あり、コラボレーション機能
- **Adobe XD**: プロトタイプ機能が充実
- **Sketch**: Mac専用、プラグインが豊富
- **Balsamiq**: 手書き風、シンプル

#### プロトタイプ作成ツール
- **InVision**: コラボレーション機能
- **Marvel**: シンプル、無料版あり
- **Principle**: アニメーション機能
- **Framer**: 高度なインタラクション

### 5.2 テンプレート

#### 基本レイアウトテンプレート
```
- ヘッダー固定レイアウト
- サイドバー付きレイアウト
- フルスクリーンレイアウト
- カード型レイアウト
```

#### コンポーネントテンプレート
```
- ナビゲーション
- フォーム
- カード
- ボタン
- モーダル
```
