### ☕ Java

#### 2.1 言語概要

- **設計思想**: "Write Once, Run Anywhere" - プラットフォーム独立性

#### 2.2 主要特徴
```java
// Java 21の現代的な記法例
public class UserService {
    private final UserRepository repository;
    private final PasswordEncoder passwordEncoder;
    
    public UserService(UserRepository repository, PasswordEncoder passwordEncoder) {
        this.repository = repository;
        this.passwordEncoder = passwordEncoder;
    }
    
    // Records (Java 14+)
    public record AuthResult(boolean success, User user, String token, String error) {}
    
    // Switch Expressions (Java 14+)
    public AuthResult authenticate(String email, String password) {
        return repository.findByEmail(email)
            .map(user -> switch (passwordEncoder.matches(password, user.getPassword())) {
                case true -> new AuthResult(true, user, generateToken(user), null);
                case false -> new AuthResult(false, null, null, "Invalid password");
            })
            .orElse(new AuthResult(false, null, null, "User not found"));
    }
    
    // Streams API
    public List<User> getActiveUsers() {
        return repository.findAll().stream()
            .filter(User::isActive)
            .sorted(Comparator.comparing(User::getCreatedAt))
            .collect(Collectors.toList());
    }
    
    // Text Blocks (Java 15+)
    private String generateEmailTemplate(String username) {
        return """
            Hello %s,
            
            Welcome to our novel sharing platform!
            
            Best regards,
            The Team
            """.formatted(username);
    }
}
```

- **エンタープライズ向け**: 大規模システム開発に適している

### 🐹 Go（Golang）

#### 2.1 言語概要
- **リリース**: 2009年（約15年、Google開発）
- **設計思想**: シンプルさと効率性を重視したシステムプログラミング言語
- **パラダイム**: 手続き型、並行プログラミング

#### 2.2 主要特徴
```go
// Go 1.21の現代的な記法例
package main

import (
    "context"
    "fmt"
    "net/http"
    "sync"
    "time"
)

type User struct {
    ID       int    `json:"id" db:"id"`
    Name     string `json:"name" db:"name"`
    Email    string `json:"email" db:"email"`
    Password string `json:"-" db:"password"`
}

type UserService struct {
    repo UserRepository
    mu   sync.RWMutex
}

func (s *UserService) Authenticate(ctx context.Context, email, password string) (*User, error) {
    user, err := s.repo.FindByEmail(ctx, email)
    if err != nil {
        return nil, fmt.Errorf("user not found: %w", err)
    }
    
    if !s.verifyPassword(password, user.Password) {
        return nil, fmt.Errorf("invalid password")
    }
    
    return user, nil
}

// Goroutines - 並行処理
func (s *UserService) GetUserStats(ctx context.Context, userID int) (map[string]int, error) {
    stats := make(map[string]int)
    var wg sync.WaitGroup
    var mu sync.Mutex
    
    // 複数のデータを並行取得
    wg.Add(3)
    
    go func() {
        defer wg.Done()
        count, _ := s.repo.GetPostCount(ctx, userID)
        mu.Lock()
        stats["posts"] = count
        mu.Unlock()
    }()
    
    go func() {
        defer wg.Done()
        count, _ := s.repo.GetFollowerCount(ctx, userID)
        mu.Lock()
        stats["followers"] = count
        mu.Unlock()
    }()
    
    go func() {
        defer wg.Done()
        count, _ := s.repo.GetLikeCount(ctx, userID)
        mu.Lock()
        stats["likes"] = count
        mu.Unlock()
    }()
    
    wg.Wait()
    return stats, nil
}

// Channels - 通信による並行処理
func (s *UserService) ProcessUsers(users []User) <-chan ProcessResult {
    resultChan := make(chan ProcessResult, len(users))
    
    go func() {
        defer close(resultChan)
        for _, user := range users {
            result := s.processUser(user)
            resultChan <- result
        }
    }()
    
    return resultChan
}
```

#### 2.3 技術的特徴
- **静的型付け**: シンプルな型システム
- **並行プログラミング**: Goroutines、Channelsによる優秀な並行処理
- **高速コンパイル**: 非常に高速なビルド時間
- **シンプルな言語仕様**: 学習しやすい言語設計
- **標準ライブラリ充実**: net/http、database/sql等が標準

#### 2.4 学習価値
- **市場需要**: ★★★★☆（クラウド・インフラ分野で急成長）
- **学習コスト**: ★★★☆☆（シンプルで学習しやすい）
- **将来性**: ★★★★★（クラウドネイティブ時代で需要急増）
- **実用性**: ★★★★☆（高性能システム開発に非常に適している）
