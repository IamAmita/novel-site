## 1. 設計方針

### 1.1 基本方針

- React SPA（Single Page Application）構成
- React Router でクライアントサイドルーティング
- コンポーネント設計：Atomic Design（atoms / molecules / organisms / pages）
- 状態管理：React Context + useReducer（シンプルな構成から開始）
- API 通信：axios + カスタムフック
- スタイル：CSS Modules

### 1.2 レスポンシブブレークポイント

| デバイス | 幅 |
|---------|---|
| スマートフォン | 〜767px |
| タブレット | 768px〜1023px |
| PC | 1024px〜 |

### 4.2 React Router 構成

```tsx
// App.tsx
<BrowserRouter>
  <Routes>
    {/* 公開ルート */}
    <Route path="/" element={<DefaultLayout />}>
      <Route index element={<TopPage />} />
      <Route path="novels" element={<NovelsPage />} />
      <Route path="novels/:id" element={<NovelDetailPage />} />
      <Route path="novels/:novelId/episodes/:episodeId" element={<ReaderLayout><EpisodeReaderPage /></ReaderLayout>} />
      <Route path="users/:id" element={<UserProfilePage />} />
      <Route path="worlds/:id" element={<WorldDetailPage />} />
      <Route path="settings/:id" element={<SettingDetailPage />} />
    </Route>

    {/* 未ログイン専用ルート */}
    <Route element={<GuestOnlyRoute />}>
      <Route path="login" element={<LoginPage />} />
      <Route path="register" element={<RegisterPage />} />
    </Route>

    {/* ログイン必須ルート */}
    <Route element={<PrivateRoute />}>
      <Route path="/" element={<DefaultLayout />}>
        <Route path="novels/create" element={<NovelCreatePage />} />
        <Route path="novels/:id/edit" element={<NovelEditPage />} />
        <Route path="novels/:id/manage" element={<NovelManagePage />} />
        <Route path="novels/:id/episodes/create" element={<EpisodeCreatePage />} />
        <Route path="novels/:id/episodes/:epId/edit" element={<EpisodeEditPage />} />
        <Route path="notifications" element={<NotificationsPage />} />
        <Route path="bookmarks" element={<BookmarksPage />} />
        <Route path="settings/profile" element={<ProfileEditPage />} />
      </Route>
    </Route>
  </Routes>
</BrowserRouter>
```

### 4.4 API 通信設計

```typescript
// services/api.ts（イメージ）
const api = axios.create({
  baseURL: import.meta.env.VITE_API_URL ?? 'http://localhost:8000',
});

// リクエストインターセプター：JWT を自動付与
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('access_token');
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

// レスポンスインターセプター：401 時にトークンリフレッシュ
api.interceptors.response.use(
  (res) => res,
  async (error) => {
    if (error.response?.status === 401) {
      // リフレッシュトークンで再取得を試みる
    }
    return Promise.reject(error);
  }
);
```

## 5. 主要コンポーネント仕様

### 5.1 NovelCard（小説カード）

| Props | 型 | 説明 |
|-------|---|------|
| `novel` | `Novel` | 小説データ |
| `showAuthor` | `boolean` | 作者名表示の有無 |
| `onClick` | `() => void` | クリックハンドラ |

表示内容：表紙画像・タイトル・あらすじ（省略）・カテゴリ・タグ・更新日・話数・閲覧数

### 5.2 EpisodeReader（本文表示）

| Props | 型 | 説明 |
|-------|---|------|
| `episode` | `Episode` | 話データ |
| `writingMode` | `'vertical' \| 'horizontal'` | 縦書き・横書き |
| `fontSize` | `number` | フォントサイズ（px） |

機能：ルビ記法のパース表示・縦書き / 横書き切替・フォントサイズ調整

### 5.3 Header

| Props | 型 | 説明 |
|-------|---|------|
| `variant` | `'default' \| 'reader'` | 表示バリアント |

`default`：フルナビゲーション（検索バー・ログインボタン・通知アイコン）
`reader`：簡易ヘッダー（作品名・戻るボタン・設定アイコン）

## 6. 画面遷移フロー

### 6.1 新規ユーザーの基本フロー

```
トップページ (/)
  └→ 新規登録 (/register)
       └→ ログイン (/login)
            └→ トップページ（ログイン済み）
                 └→ 小説一覧 (/novels)
                      └→ 小説詳細 (/novels/:id)
                           └→ 話閲覧 (/novels/:novelId/episodes/:episodeId)
```

### 6.2 作者の投稿フロー

```
ログイン済みトップページ
  └→ 小説作成 (/novels/create)
       └→ 話管理 (/novels/:id/manage)
            └→ 話作成 (/novels/:id/episodes/create)
                 └→ 話閲覧（プレビュー確認）
```

### 6.3 設定管理フロー

```
小説詳細 (/novels/:id)
  └→ 世界観一覧 (/novels/:id/worlds)
       └→ 世界観詳細 (/worlds/:id)
            └→ 設定詳細 (/settings/:id)
```
