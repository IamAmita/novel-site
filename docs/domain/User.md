## データモデル

### User（アカウント）

| フィールド | 型・制約 |
|---|---|
| id | 内部主キー（サロゲートキー）。不変、他エンティティからの外部キー参照はすべてこのidを使う |
| email | 文字列、必須、一意 |
| user_id | 文字列、必須、一意。英数字・アンダースコアのみ、3〜20文字。**変更不可の公開識別子**（idとは別物） |
| username | 文字列、必須。**重複可**（一意性はuser_idが担保する） |
| icon | 画像、任意 |
| bio | 文字列、任意（自己紹介） |
| password | 必須（ハッシュ化して保存） |
| created_at / updated_at | タイムスタンプ |
| deleted_at | 論理削除用（NULLなら有効） |

#### 決定事項

**id と user_id の役割分担**（2026-07-28決定）
- `id`: 不変の内部主キー（サロゲートキー）。他エンティティ（PenName等）からの外部キー参照は常にこちらを使う。ユーザーからは見えない
- `user_id`: 変更不可の公開識別子。プロフィールURL等ユーザーに見える箇所で使う

**ログイン方法**
- メールアドレス＋パスワード、またはユーザーID＋パスワードのどちらでも可

**ユーザーID（user_id）の仕様**
- 本人が登録時に決める一意な識別子（Xの@handle相当）。英数字・アンダースコアのみ、3〜20文字
- プロフィールURLにそのまま使用する（例: `/u/{user_id}`）
- メールアドレスの代わりにログインにも使用できる
- **変更不可**（2026-07-28決定）。旧ID再利用不可や変更回数制限といった論点を避けるため、一旦は変更不可でシンプルに運用する

**ユーザー名（username）の仕様**
- 登録時に決める表示名。ユーザーIDとは別の概念で、識別子ではなく単なる表示名
- 重複可（他ユーザーと同じユーザー名でもよい。一意性はユーザーIDのみが担保する）
- 変更可能（回数制限なし）
- **User情報とPenName情報は完全に分離する**（2026-07-28決定）。usernameはPenNameの初期値・フォールバック等には使わない。アカウント設定上の表示名にとどまる

**icon・bioの仕様**（2026-07-28決定）
- User自体にもicon（アイコン画像）・bio（自己紹介）を持たせる。**PenNameのicon・bioとは独立したアカウント設定上のプロフィール**であり、初期値のコピーやフォールバックとしては使わない（User/PenName完全分離の方針に合わせる）
- bioの制限（2026-08-22決定）: **World.descriptionと同じルール**（DB型は`TextField`、アプリ側バリデーションで上限1024文字）。PenName.bioにも同じ制限を適用する

**パスワードリセット**
- メール送信によるリセット

**アカウント削除**
- 論理削除（配下のペンネーム・World・作品等も連鎖的に論理削除。[functional-scope.md](../business/functional-scope.md) B参照）

### PenName（ペンネーム）

| フィールド | 型・制約 |
|---|---|
| id | 内部主キー（サロゲートキー）。不変、World.owner_pen_name等の外部キー参照はすべてこのidを使う |
| user | 所属アカウント（外部キー） |
| display_name | 文字列、必須。**同一user内で一意**、異なるuser間では重複を許容 |
| icon | 画像、任意 |
| bio | 文字列、任意（自己紹介） |
| created_at / updated_at | タイムスタンプ |
| deleted_at | 論理削除用（NULLなら有効） |

#### 決定事項

**作成タイミング**（2026-07-28決定）
- ユーザー登録時にはペンネームを作成しない。**登録直後はペンネーム0件が正常状態**
- **World作成時**、ペンネームを1件も持っていなければ、その場でペンネーム作成を強制してからWorld作成に進む（World作成には`owner_pen_name`の選択が必須なため、自然な作成タイミングとして採用）
- 作成するペンネームの初期値はUser情報からコピーせず、ここで新規に入力させる（User情報とPenName情報は完全に分離する方針のため）

**作成数・命名ルール**
- 1アカウントで複数のペンネームを作成可能（上限なし）
- ペンネーム名の重複: 同一ユーザー内では禁止、異なるユーザー間では許容

**コンテンツ作成時の名義選択**
- World作成時、保有するペンネームの中から使用するペンネームを選択する（0件の場合は上記「作成タイミング」の通りその場で作成させる）。（Cの[World.md](World.md)における`owner_pen_name`はここで選択されたペンネームを指す）

**削除の可否**（2026-07-28決定）
- そのペンネームが**Worldを1件も保持していなければ削除可能**。**1件でも保持していれば削除不可**（Worldの`owner_pen_name`が指す先を失わせないため。結果としてペンネーム0件に戻ることもある）

**「ペンネーム切り替え」機能について**（2026-07-23決定）
- グローバルな「ペンネーム切り替え」機能は持たない。「今アクティブなペンネーム」をユーザー設定側で選ぶのではなく、Worldごとに名義（ペンネーム）を作成時に選択し、後から変更もできる形にする（詳細は[World.md](World.md)参照）

## 画面仕様

### ペンネーム一覧画面

- 表示内容（2026-08-22決定）: **シンプルな一覧**。アイコン・表示名（display_name）・所属World数のみを表示する（作品数等の統計情報は含めない）
- 各ペンネームから編集画面・削除操作へ遷移できる
