## データモデル

### User（アカウント）

| フィールド | 型・制約 |
|---|---|
| email | 文字列、必須、一意 |
| user_id | 文字列、必須、一意。英数字・アンダースコアのみ、3〜20文字 |
| username | 文字列、必須。**重複可**（一意性はuser_idが担保する） |
| password | 必須（ハッシュ化して保存） |
| created_at / updated_at | タイムスタンプ |
| deleted_at | 論理削除用（NULLなら有効） |

#### 決定事項

- ログイン方法: **メールアドレス＋パスワード、またはユーザーID＋パスワードのどちらでも可**
- ユーザーID: **本人が決める一意な識別子**（Xの@handle相当）。英数字・アンダースコアのみ、3〜20文字
  - プロフィールURLにそのまま使用する（例: `/u/{user_id}`）
  - メールアドレスの代わりにログインにも使用できる
  - 作成後も**変更可能（回数制限あり）**。具体的な回数・旧IDの扱い（再利用可否等）は実装設計時に検討
- ユーザー名（デフォルト表示名）: **登録時に決める表示名**。ユーザーIDとは別の概念で、識別子ではなく単なる表示名
  - **重複可**（他ユーザーと同じユーザー名でもよい。一意性はユーザーIDのみが担保する）
  - **変更可能（回数制限なし）**
  - ペンネームを1件も作成していない場合、コンテンツ作成時の著者名としてこのユーザー名が使われる（フォールバック表示名）。ペンネームを1件以上作成している場合は、コンテンツ作成時にペンネームから選択する
- パスワードリセット: メール送信によるリセット
- アカウント削除: 論理削除（配下のペンネーム・World・作品等も連鎖的に論理削除。[functional-scope.md](../business/functional-scope.md) B参照）

### PenName（ペンネーム）

| フィールド | 型・制約 |
|---|---|
| user | 所属アカウント（外部キー） |
| display_name | 文字列、必須。**同一user内で一意**、異なるuser間では重複を許容 |
| icon | 画像、任意 |
| bio | 文字列、任意（自己紹介） |
| created_at / updated_at | タイムスタンプ |
| deleted_at | 論理削除用（NULLなら有効） |

#### 決定事項

- 1アカウントで複数のペンネームを作成可能（**上限なし**、0件も可）
- ペンネーム名の重複: **同一ユーザー内では禁止、異なるユーザー間では許容**
- World・作品等のコンテンツを新規作成する際、**ペンネームを1件以上作成していればその中から使用するペンネームを選択する**（Cの[World.md](World.md)における`owner_pen_name`はここで選択されたペンネームを指す）。ペンネームが0件の場合は、Userの「ユーザー名（デフォルト表示名）」が著者名として使われる
- **グローバルな「ペンネーム切り替え」機能は持たない**（2026-07-23決定）。「今アクティブなペンネーム」をユーザー設定側で選ぶのではなく、Worldごとに名義（ペンネーム）を作成時に選択し、後から変更もできる形にする（詳細は[World.md](World.md)参照）
