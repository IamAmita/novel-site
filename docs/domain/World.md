## データモデル

| フィールド | 型・制約 |
|---|---|
| name | 文字列、必須、上限100文字 |
| description | 文字列（TextField / DB上はTEXT型）、任意、アプリ側バリデーションで上限1024文字 |
| cover_image | 画像、任意（未設定時は共通デフォルト画像を表示） |
| owner_pen_name | 所有ペンネーム（外部キー、**PenName.idを参照**） |
| created_at / updated_at | タイムスタンプ |
| deleted_at | 論理削除用（NULLなら有効） |
| deleted_by | 削除実行者（外部キー、User参照、任意）。管理者による強制削除の判定に使う。詳細は[Moderation.md](Moderation.md)参照 |

### 決定事項

- name: **必須・上限100文字**
- description: **任意・上限1024文字**。DB型は`TextField`（PostgreSQLのTEXT型。VARCHAR(n)と性能差はないため）とし、DBレベルでは長さを制約しない。1024文字の上限はアプリ側バリデーション（`MaxLengthValidator(1024)`）で担保する。文字数ベースの制限のため日本語でも1024文字入力可能
- 表紙画像: **任意**。未設定時は共通デフォルト画像を表示
- 論理削除: **期限なく手動復元可能**（ユーザー自身が一覧から復元できるUIを用意する）
- 名前重複: **許容**（同一ペンネーム内でも同名Worldを複数作成できる）
- 削除時の配下データ（Setting・作品等）: **連鎖的に論理削除**
- owner_pen_name: **作成時に選択し、作成後も編集画面から変更できる**（2026-07-23決定）。グローバルな「ペンネーム切り替え」機能は持たず、名義の指定・変更はWorldごとに行う（[User.md](User.md)参照）
- owner_pen_name の参照キー: **PenName.id（サロゲートキー）を参照する**（2026-07-28決定）。display_name等の可変値ではなく不変のidで参照する

## 画面仕様

### World一覧画面

- 表示形式: **リスト形式**（テキスト中心。カード形式は採用しない）
- 対象範囲: **自分が所有するWorld＋共同制作者として招待されているWorldの両方**
- デフォルトソート順: **更新日時の新しい順**
- 検索: **World名の部分一致検索**（説明文は対象外）

### World詳細画面

- 表示内容: **World基本情報（名前・説明・表紙画像）のみ**
- 配下のSetting一覧・作品一覧は、F（閲覧・検索）で定義した別メニュー（設定一覧／作品一覧）側で確認する構成とし、World詳細画面には含めない
- 共同制作者権限に応じた表示差分（2026-08-22決定、[Collaboration.md](Collaboration.md)の権限マトリクス参照）:
  - `view`（閲覧のみ）: 編集・削除ボタン、共同制作者管理への導線を表示しない
  - `edit`（編集可）: 編集ボタン（名前・説明・表紙画像の編集）を表示。削除・名義変更・共同制作者管理は表示しない
  - `full`（全権限）: 編集・削除・名義変更・共同制作者管理のすべてを表示

### World作成・編集フォーム

- 入力項目: 名前（必須）、説明（任意）、表紙画像（任意）、名義（ペンネーム、必須。作成済みペンネームから選択。ペンネーム0件の場合はその場でペンネーム作成を強制してから選択させる。[User.md](User.md)参照）
- 名前の重複チェックは行わない（重複を許容するため）
- 名義（ペンネーム）は編集フォームから後で変更できる

### World削除

- 論理削除
- 削除確認: **単純な確認ダイアログ**（配下のSetting・作品件数などは表示しない）
- 削除後の復元: 期限なく可能。復元UIは別途提供（一覧画面からの手動復元を想定）
- 復元対象の制限（2026-08-22決定）: `deleted_by`が管理者による削除の場合は、この復元UIの対象外とする（詳細は[Moderation.md](Moderation.md)参照）
