# ユーザーストーリー

**目的**: 技術に依存しない「何を作るか」の定義
**対象**: python-django実装で実現すべき機能
**参照**: [Phase1-確定メモ](../project/Phase1-確定メモ.md)、[functional-scope.md](./functional-scope.md)、[core-entities.md](../domain/core-entities.md)

> Phase 1 の対象ユーザーは **作者のみ**（自分自身）。読者・共同制作者・一般公開は Phase 2 以降。

---

## Phase 1: 作者（Author）のストーリー

### 1. アカウント・ペンネーム管理

- **As a** 作者
- **I want to** アカウントを登録し、複数のペンネームを使い分ける
- **So that** 創作ごとにアイデンティティを分けられる

#### 受け入れ条件
- [ ] メールアドレスで新規登録できる
- [ ] ログイン・ログアウトができる
- [ ] パスワードを変更・リセットできる
- [ ] 複数のペンネーム（表示名・アイコン・自己紹介）を作成・切り替えできる
- [ ] アカウントを削除できる

---

### 2. 世界観（World）管理

- **As a** 作者
- **I want to** World（世界観）を作成・管理する
- **So that** 作品と設定をまとめる器を持てる

#### 受け入れ条件
- [ ] World を作成・編集・削除できる
- [ ] World の一覧を確認できる
- [ ] World 名で検索できる

---

### 3. 設定（Setting）管理 — 最優先領域

- **As a** 作者
- **I want to** 設定を自由かつ詳細に管理する
- **So that** 世界観に一貫性を持たせながら執筆できる

#### 受け入れ条件
- [ ] キャラクター・世界地理・組織勢力・物品アイテム・歴史等、種類ごとに Setting を作成・編集・削除できる
- [ ] 設定テンプレート（種類）は初期セットから選べるほか、自由に追加できる
- [ ] 設定ごとにカスタム項目を追加できる（テンプレート由来の雛形項目＋個別追加のハイブリッド）
- [ ] 設定同士の関係性を方向性付きで定義できる（例：「A の師匠は B」）
- [ ] 関係ラベルはシステム共通マスタから選ぶか、World 固有に追加できる
- [ ] 設定は World 単位（World 内の全作品で共有）または作品単位（その作品専用）のどちらかで管理できる
- [ ] 設定を一覧・検索できる
- [ ] （任意）設定間の関係性を視覚化できる

---

### 4. 作品・執筆

- **As a** 作者
- **I want to** 作品を執筆・管理する
- **So that** World の中で物語を形にできる

#### 受け入れ条件
- [ ] 作品（タイトル・あらすじ・表紙画像）を作成・編集・削除できる
- [ ] 章・話の構成で本文を管理できる
- [ ] 執筆画面から設定を参照できる（本文中のリンク記法からの自動反映、またはサイドパネルからの手動追加）
- [ ] 変更履歴・編集ログを確認できる

---

### 5. 閲覧・検索（自分向け）

- **As a** 作者
- **I want to** 自分の作品・設定を見返す
- **So that** 執筆内容を振り返り整理できる

#### 受け入れ条件
- [ ] World / 作品 / 話 / 設定をそれぞれ一覧できる（設定一覧・作品一覧は別メニュー）
- [ ] 一覧をソートできる
- [ ] 作品・本文を検索できる
- [ ] 設定を検索できる

---

## Phase 2 以降のストーリー（参考・現時点では未実装）

以下は [functional-scope.md](./functional-scope.md) で Phase 2 以降と定義されている機能に対応するストーリー。Phase 1 実装では扱わない。

### 共同創作（Phase 2 最優先）
- **As a** 作者
- **I want to** 他の作者と共同で World・作品を作る
- **So that** より豊かな作品を創作できる

想定される受け入れ条件: 共同制作者の招待・権限管理、進捗管理、変更履歴の共有、公開前評価（ベータレビュー）

### 限定公開・コミュニケーション（Phase 2）
- **As a** 作者
- **I want to** 共同制作者や限られた相手に作品・設定を公開する
- **So that** フィードバックを得られる

想定される受け入れ条件: 限定公開設定、コメント・評価、フォロー、DM、掲示板

### 一般公開・読者向け機能（Phase 3 以降）
- **As a** 読者
- **I want to** 公開された作品を見つけて読む
- **So that** 新しい作品に出会える

想定される受け入れ条件: 一般公開・閲覧、お気に入り・ブックマーク、関連作品・おすすめ・ランキング、通知

### 管理機能（Phase 3 以降）
- **As a** 管理者
- **I want to** サイトを適切に運営する
- **So that** 安全で快適な環境を提供できる

想定される受け入れ条件: ユーザー・コンテンツ管理、通報対応、利用状況・統計の確認

## 🎯 Phase 1 の成功基準

[Phase1-確定メモ §1](../project/Phase1-確定メモ.md) に準拠。

- 設定管理が自由かつ詳細にできる
- 設定を執筆画面から参照できる
- 設定を見ながら執筆できる

同時接続数・コミュニティ活性度等の指標は Phase 1（個人利用が前提）では対象外。Phase 2 以降で利用者が増えた段階で改めて定義する。
