## A. 全体方針・ドメイン構造

- **ドメイン構造**: 作者 → ペンネーム → World（世界観）→ Setting（設定）／作品 → 章 → 話
- **対象ユーザー**: 作者（＋B以降で読者・共同制作者等の役割が加わる可能性あり。全機能要件が固まった時点で役割ごとの整理を行う）

## B. ユーザー・ペンネーム管理

| 機能 | 内容 |
|------|------|
| ユーザー登録 | メールアドレス＋パスワードで新規登録できる。登録時にユーザーID（一意な識別子）とユーザー名（表示名）を決める |
| ログイン／ログアウト | メールアドレス＋パスワード、またはユーザーID＋パスワードのいずれでもログインできる |
| パスワード変更 | ログイン中に変更できる |
| パスワードリセット | パスワード忘失時に、登録メールアドレス宛のメール経由でリセットできる |
| アカウント削除 | 自分のアカウントを削除できる（論理削除。物理削除はしない） |
| ペンネーム作成 | 1ユーザーが複数のペンネームを作成できる（上限なし） |
| ペンネーム編集 | 表示名・アイコン・自己紹介を編集できる |
| ペンネーム削除 | ペンネームを削除できる |

### 決定事項

- アカウントとペンネームの関係: **1アカウント（メールアドレス＋パスワードでログイン）に対し、複数のペンネームを持てる**（Worldや作品等のコンテンツ作成時に、どのペンネーム名義で作るかを選択する）
- 「ペンネーム切り替え」は**ユーザー機能として持たない**（2026-07-23決定）。ログイン中に「今アクティブなペンネーム」を選ぶグローバルな概念は設けず、**Worldごとに名義（ペンネーム）を設定・変更する**形にする（C. 世界観 参照）
- ユーザーID: **本人が決める一意な識別子**（Xの@handleのようなもの）。プロフィールURLにそのまま使用し、メールアドレスの代わりにログインにも使用できる。**変更不可**（2026-07-28決定）
- ユーザー名: **登録時に決める表示名**（ユーザーIDとは別概念、重複可、変更自由）。User情報とPenName情報は完全に分離し、著者名フォールバックとしては使わない（2026-07-28決定）
- ペンネーム数の上限: **なし**。登録時には作成せず0件からスタートし、**World作成時に0件ならその場で作成を強制する**（2026-07-28決定）
- ペンネーム名の重複: **同一ユーザー内では禁止、異なるユーザー間では許容**
- パスワードリセット手段: **メール送信によるリセット**（メール送信基盤が必要）
- アカウント削除時の配下データ（ペンネーム・World・作品等）: **論理削除**（物理削除はせず、データは保持したまま非表示・利用不可にする。復元可否や保持期間は実装設計時に検討）

> データモデル・画面仕様の詳細は [User.md](../domain/User.md) を参照

## C. 世界観（World）

| 機能 | 内容 |
|------|------|
| World作成 | 作成時に使用するペンネーム（名義）を選択して World を作成できる |
| World編集 | 名前・説明・表紙画像に加え、名義（ペンネーム）を編集できる |
| World削除 | World を削除できる |
| World一覧 | 自分の World を一覧できる |
| World検索 | World名で検索できる |

### 決定事項

- 表紙画像: **必要**（作品と同様、World にも表紙画像を設定できる）
- World削除時の配下データ（Setting・作品等）: **連鎖削除**（論理削除。B のアカウント削除と同様の方針）
- World名の重複: **許容**（同一ペンネーム内でも同名の World を複数作成できる）
- 名義（ペンネーム）: Worldの`owner_pen_name`は**作成時に選択し、作成後も編集画面から変更できる**（2026-07-23決定。ユーザー機能としての「ペンネーム切り替え」は持たず、World側の名義設定として扱う）

## D. 設定（Setting）

| 機能 | 内容 |
|------|------|
| Setting作成 | World単位（World内の全作品で共有）または作品単位（その作品専用）でSettingを作成できる |
| Setting編集 | 名前・説明・カスタム項目を編集できる |
| Setting削除 | Settingを削除できる |
| Setting一覧・詳細 | 一覧・詳細を確認できる（親子階層を含む） |
| Setting検索 | 名前・内容で検索できる |
| 親子階層 | Setting同士を親子関係（ツリー）で整理できる（例：「王国」の下に「首都」） |
| 設定テンプレート管理 | Settingの種類（テンプレート）を作成・編集・削除できる |
| カスタム項目 | Settingごとにテンプレート由来の項目＋個別の項目を追加できる。項目にはテキスト、または他のSettingへの参照を入力できる |
| 設定間の関係性 | Setting同士に方向性を持った関係を設定できる（例：「Aの師匠はB」）。World をまたいだ関係も設定できる |
| 関係ラベル管理 | 関係の種類（「師匠」等）はマスタから選ぶほか、自由に追加できる |

### 決定事項

- Setting の範囲: **World単位＋作品単位の両方**（作品固有の設定も作れる）
- 親子階層構造: **必要**
- Setting削除時: **連鎖削除**（論理削除）
- Setting名の重複: **許容**
- SettingTemplate初期セット: キャラクター／世界・地理／組織・勢力／物品・アイテム／歴史（ユーザーは自由に追加・編集・削除可能。初期セットも例外ではない）
- SettingFieldの値: **テキスト＋他Settingへの参照**（数値・日付等の型は Phase 1 では扱わない）
- 関係性の方向性: **あり**
- 関係ラベルの管理: **マスタ管理（自由追加可）**
- 関係性のWorld横断: **可**（World をまたいだ Setting 同士の関係も設定できる）
- 関係性の視覚化: **Phase 1 に含めない**

## E. 作品・執筆（Novel / Chapter / Episode）

| 機能 | 内容 |
|------|------|
| 作品作成 | World の下に作品（タイトル・あらすじ・表紙画像）を作成できる |
| 作品編集・削除 | 作品を編集・削除できる |
| 章（Chapter）管理 | 章を作成できる（任意。章を作らず話だけで作品を構成することもできる） |
| 話（Episode）執筆 | 話のタイトル・本文を執筆・編集できる |
| 設定参照 | 執筆画面から Setting を参照できる。本文中のリンク記法での参照と、サイドパネルから選んで挿入する方法の両方に対応する |
| 変更履歴 | Setting・作品本文（World/Novel/Chapter/Episode）の変更について、誰がいつ何を変更したかの変更ログを記録・確認できる |

### 決定事項

- 章（Chapter）: **任意**（章なしで話だけの作品も作れる）
- 設定参照の方式: **本文中のリンク記法＋サイドパネルからの挿入の両方**
- 変更履歴の対象: **Setting＋作品本文**
- 変更履歴の粒度: **変更ログのみ**（誰がいつ何を変更したかの記録。全文スナップショットや差分の保存は行わない）

## F. 閲覧・検索

| 機能 | 内容 |
|------|------|
| 設定一覧 | 自分の Setting を一覧できる（作品一覧とは別メニュー） |
| 作品一覧 | 自分の作品を一覧できる（設定一覧とは別メニュー） |
| 設定検索 | 設定名で部分一致検索できる |
| 作品・本文検索 | 作品タイトル・本文で部分一致検索できる |
| World検索 | World名で部分一致検索できる |

### 決定事項

- 閲覧画面の基本構成: **「設定一覧」「作品一覧」を別メニューに分ける**（World横断で一覧表示）
- 検索方式: **部分一致検索**
- World検索: **必要**

## G. 非機能・運用

| 機能 | 内容 |
|------|------|
| データエクスポート | 作品単位・設定単位でデータをエクスポートできる |
| テスト | 各機能の実装とあわせてテストコードを書く（テスト駆動を志向） |

### 決定事項

- パフォーマンス要件: **不要**（個人利用前提のため厳密な数値目標は設けない）
- バックアップ方針: DBの定期バックアップに加えて、**作品・設定単位のエクスポート機能を用意する**（ユーザーが自分でデータを書き出せる）
- テスト方針: **テスト駆動**（機能実装と合わせてテストコードを書く。実装計画時に具体的な粒度・ツールを検討）

## H. 共同制作

| 機能 | 内容 |
|------|------|
| 共同制作者の招待 | World単位・作品単位のどちらでも、他のユーザーを共同制作者として招待できる |
| 招待の承諾・辞退 | 招待されたユーザーは承諾・辞退できる |
| 権限管理 | 共同制作者ごとに「閲覧のみ」「編集可」「全権限」のいずれかの権限を設定できる |
| 共同制作者一覧・解除 | 共同制作者を一覧・除名できる |
| 掲示板 | 作品単位で、共同制作者間の議論・相談ができる掲示板を持てる |
| 進捗管理 | 作品全体のステータス（執筆中・レビュー中・完成等）を共有できる |
| 公開前評価 | 完成前の作品・話に、共同制作者が自由コメントを付けられる（I. コミュニケーションのコメント機能を共同制作者限定で利用） |
| 変更履歴の共有 | 共同制作者は E で定義した変更履歴（Setting・作品本文の変更ログ）を確認できる |

### 決定事項

- 招待の単位: **World単位・作品単位の両方**
- 権限の粒度: **閲覧のみ／編集可／全権限** の3段階
- 招待権限: **所有者、および所有者が許可した共同制作者も招待できる**
- 掲示板の単位: **作品単位**
- 進捗管理: **作品全体のステータス**（話単位の細かい進捗管理はしない）
- 公開前評価: **自由コメントのみ**（承認フロー等は設けない）

## I. コミュニケーション

| 機能 | 内容 |
|------|------|
| コメント | 作品全体・話（Episode）単位の両方にコメントを投稿できる |
| 返信 | コメントに返信できる |
| コメント削除 | 自分のコメント、または作者が自分の作品へのコメントを削除できる |
| 評価 | 作品に5段階評価を付けられる |
| フォロー | 他のユーザー（作者）をフォローできる |
| 更新通知・フィード | フォローした作者の新作・更新を通知・一覧で確認できる |
| DM | 相互フォロー関係にあるユーザー同士でダイレクトメッセージを送受信できる |

### 決定事項

- コメント対象: **作品＋話の両方**
- 評価方式: **5段階評価**
- フォローの目的: **更新通知・フィード表示のため**
- DMの相手範囲: **相互フォローのみ**

## J. 公開・共有

| 機能 | 内容 |
|------|------|
| 公開範囲設定（作品） | 作品ごとに非公開／限定公開／一般公開を設定できる |
| 公開範囲設定（話） | 話（Episode）単位でも公開範囲を上書き設定できる（例：既公開分のみ見せ、最新話は非公開のまま） |
| 限定公開の対象指定 | 共同制作者には自動的に見えるほか、それ以外の個別ユーザーを指定して限定公開できる |
| Setting公開 | 作品本文とは別に、Setting（設定）ごとに公開・非公開を作者が選べる |

### 決定事項

- 公開範囲の単位: **作品単位＋話単位**（話ごとに上書き可能）
- 限定公開の対象指定: **共同制作者への自動限定公開＋個別ユーザー指定の両方**
- Setting公開: **作者が個別に選んで公開できる**（作品公開と連動して自動公開はしない）

## K. 読者向け機能

| 機能 | 内容 |
|------|------|
| 一般読者向け閲覧 | 一般公開された作品を、未登録ユーザーでも閲覧できる |
| タグ・カテゴリ | 作品にタグ・ジャンルを付与でき、検索・絞り込みに使える |
| 公開作品検索 | タイトル・作者名・タグ等で公開作品を検索できる |
| お気に入り・ブックマーク | 気に入った作品をお気に入り登録できる |
| おすすめ・ランキング | 閲覧数・評価・お気に入り数等の集計に基づく、おすすめ・ランキング表示 |
| 通知 | コメント・フォロー・更新等をアプリ内通知で受け取れる |

### 決定事項

- 未登録ユーザーの閲覧: **可**（一般公開作品はアカウントなしでも読める）
- タグ・カテゴリ: **必要**
- ランキング算出基準: **閲覧数・評価・お気に入り数などの集計**
- 通知手段: **アプリ内通知のみ**（メール通知はしない）

## L. 管理機能

| 機能 | 内容 |
|------|------|
| 通報 | 公開コンテンツ（作品・コメント）を通報できる |
| 通報対応 | 管理者が通報内容を確認し、対応（削除・警告・停止等）できる |
| コンテンツ削除 | 管理者が不適切な公開コンテンツを削除できる |
| アカウント対応 | 管理者がユーザーに警告・一時停止・永久停止の対応を行える |
| 管理者権限 | 管理者ロールを持つユーザーのみ管理機能にアクセスできる |

### 決定事項

- 管理者体制: **開発者（自分）のみ**を想定（複数管理者体制は将来の拡張として設計に含めない）
- 通報・モデレーション対象: **公開コンテンツ全般**（作品・コメント両方）
- アカウント対応の粒度: **警告・一時停止・永久停止の段階制**
