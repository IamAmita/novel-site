## 入力項目・バリデーション

| 項目 | 制約 |
|---|---|
| 所属World | 必須・**作成時のみ指定、編集時は表示のみ**（Novel.mdの決定どおり変更不可） |
| title | 必須。重複許容（チェックなし） |
| synopsis | 任意 |
| cover_image | 任意（未設定時は共通デフォルト画像） |

- 名義は所属Worldの`owner_pen_name`を表示するのみ（選択不可、Novel.mdの決定どおり）
- Phase 1ではstatus・visibility・categoryは実装しないためフォームに置かない（[Phase1-確定メモ.md](../../../project/Phase1-確定メモ.md) §3.1）
- 保存でChangeLogに記録
