# SC-15 作品一覧画面

- **URL**: `/novels`
- **区分**: E. 作品・執筆／F. 閲覧・検索
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[Novel.md](../../../domain/Novel.md)、[functional-scope.md](../../../business/functional-scope.md) F

## 目的

World横断で自分の作品を一覧・検索する。「作品一覧」グローバルメニューに対応。削除済み作品の復元もここで行う。

## ワイヤーフレーム

```
┌──────────────────────────────────────────┐
│ 作品一覧   [検索:        ]  [＋新規作成]  │
│ World: [すべて ▼]    削除済みを表示 [OFF] │
│                                          │
│ 剣と魔法の物語     異世界オルディア        │
│   あらすじ先頭1行…  話数: 12  更新: 09-01 │
│ ──────────────────────────────           │
│ 電脳都市の探偵     近未来都市トーキョー     │
│   あらすじ先頭1行…  話数: 3   更新: 08-20 │
└──────────────────────────────────────────┘
```

## 表示要素・操作

- **リスト形式**（World一覧にならう、Novel.mdの決定どおり）。各行: タイトル・所属World名・あらすじ先頭1行・話数・更新日時
- ソート: 更新日時の新しい順。Worldフィルタあり（SC-11と同じパターン）
- 検索: **タイトル・本文の部分一致**。本文ヒット時は「どの話でヒットしたか」を行の下に補足表示（例: 「第3話 本文にヒット」）
- 「削除済みを表示」トグル: 共通パターンどおり（復元ボタン付き）
- 行クリックでSC-16へ

## 画面遷移

- **遷移元**: ヘッダーの「作品一覧」
- **遷移先**: 行クリック → SC-16、＋新規作成 → SC-17

## 設計時の判断（要レビュー）

1. 本文検索のヒット箇所は一覧行に補足表示
