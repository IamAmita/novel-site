# SC-18 話（Episode）執筆画面

- **URL**: `/episodes/:id`
- **区分**: E. 作品・執筆
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[Novel.md](../../../domain/Novel.md)、[Setting.md](../../../domain/Setting.md)

## 目的

話のタイトル・本文を執筆する。設定（Setting）をリンク記法＋サイドパネルで参照しながら書ける。保存のたびにChangeLogへ記録される。

## ワイヤーフレーム

```
┌────────────────────────────────────────────────┐
│ ← 剣と魔法の物語   [変更履歴]  保存済み [ 保存 ] │
│ タイトル [第1話 村の朝            ]             │
├───────────────────────────────┬────────────────┤
│                               │ 設定パネル [×] │
│  本文エリア                    │ [検索:      ]  │
│                               │ ▼ キャラクター  │
│  朝もやの中、[[アリシア]]は     │   アリシア [挿入]│
│  剣を手に取った。……            │   ガレオン [挿入]│
│                               │ ▶ 世界・地理    │
│                               │ ─────────      │

│                               │ 性格: 勝気      │
│                               │ 所在地: 王都グラン│
└───────────────────────────────┴────────────────┘
```

## レイアウト

- 左: 本文エリア、右: 開閉式の**設定サイドパネル**（デフォルト開。閉じると本文が全幅）
- ヘッダー: 作品詳細（SC-16）への戻りリンク・変更履歴ボタン・保存状態表示（「保存済み」「未保存の変更あり」）・保存ボタン

## 編集

- タイトル（必須）・本文（プレーンテキスト、文字数制限なし — Novel.mdの決定どおり）

## 設定参照

- 本文中に `[[Setting名]]` のリンク記法で参照を記述できる。エディタ上では記法をハイライト表示し、クリックでサイドパネル下部にそのSettingの内容（名前・説明・カスタム項目）をプレビュー表示
- サイドパネル: この作品が参照できるSetting（所属WorldのWorld共有Setting＋この作品専用のSetting）をテンプレート別にツリー表示＋検索。「挿入」でカーソル位置に `[[Setting名]]` を挿入
- `[[存在しない名前]]` はエラーにせず通常テキスト扱い（薄いハイライトで「未解決」表示）

## 保存

- **明示的な保存ボタン方式。自動保存は行わない**（1回の保存＝1つのChangeLogレコード。自動保存だと履歴が細切れになりdiff体験を損ねるため）
- 未保存の変更がある状態でのページ離脱時は確認を出す

## 画面遷移

- **遷移元**: SC-16（話クリック・話の新規作成直後）
- **遷移先**: ← 戻りリンク → SC-16、変更履歴 → SC-19（`/changelog/episode/:id`）、サイドパネルのSetting名クリック → SC-12（別タブ表示 — 執筆中の本文を失わないため）

## 設計時の判断（要レビュー）

1. 本文はプレーンテキスト（リッチテキスト・ルビ記法などはPhase 1では扱わない）
2. 保存は明示ボタン方式・自動保存なし（ChangeLogのdiff体験を優先）
3. 未解決の `[[名前]]` はエラーにしない
4. サイドパネルからSetting詳細への遷移は別タブで開く
