# SC-09 World詳細画面

- **URL**: `/worlds/:id`
- **区分**: C. 世界観（World）
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[World.md](../../../domain/World.md)

## 目的

Worldの基本情報を確認し、編集・削除・テンプレート管理・変更履歴への起点となる。

## ワイヤーフレーム

```
┌──────────────────────────────────────────┐
│ 異世界オルディア          [変更履歴] [編集] │
│ 名義: 星野 蒼                             │
│ ┌────────┐                              │
│ │ 表紙画像 │  魔法と剣の世界。大陸の東側   │
│ └────────┘  には……（説明全文）          │
│                                          │
│ [設定テンプレートを管理]                   │
│ ──────────────────────────────           │
│ [このWorldを削除]                         │
└──────────────────────────────────────────┘
```

## 表示要素・操作

- 表示: World名・名義（ペンネーム表示名）・表紙画像（未設定時は共通デフォルト画像）・説明全文
- 配下のSetting・作品一覧は**この画面に置かない**（World.mdの決定どおり。設定一覧SC-11・作品一覧SC-15側で見る）
- ボタン:
  - **変更履歴**: SC-19（`/changelog/world/:id`）へ（2026-09-03決定の個別ボタン配置）
  - **編集**: SC-10（編集モード）へ
  - **設定テンプレートを管理**: SC-14へ（2026-09-03決定の導線）
  - **削除**: ページ下部に分離配置（誤操作防止） → DL-01

## 関連ダイアログ: DL-01 World削除確認

- 「『（World名）』を削除しますか？」＋補足「削除後も一覧から復元できます」＋「キャンセル／削除する」
- 配下件数は表示しない（World.mdの決定どおり）。配下のSetting・作品は連鎖的に論理削除
- 削除実行後はSC-08へ

## 画面遷移

- **遷移元**: SC-08（行クリック）
- **遷移先**: 変更履歴 → SC-19、編集 → SC-10、テンプレート管理 → SC-14、削除 → SC-08
