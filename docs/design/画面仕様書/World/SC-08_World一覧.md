# SC-08 World一覧画面

- **URL**: `/worlds`
- **区分**: C. 世界観（World）
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[World.md](../../../domain/World.md)

## 目的

自分のWorldを一覧・検索し、詳細・作成への起点となる。削除済みWorldの復元もここで行う。ログイン後の最初の画面。

## ワイヤーフレーム

```
┌──────────────────────────────────────────┐
│ World一覧    [検索:        ] [＋新規作成] │
│                    削除済みを表示 [OFF]   │
│                                          │
│ 異世界オルディア        名義: 星野 蒼     │
│   魔法と剣の世界…       更新: 2026-09-01 │
│ ──────────────────────────────           │
│ 近未来都市トーキョー     名義: 星野 蒼     │
│   2089年の東京を…       更新: 2026-08-28 │
└──────────────────────────────────────────┘
```

## 表示要素・操作

- **リスト形式**（カードは使わない、World.mdの決定どおり）。各行: World名・説明の先頭1行・名義（ペンネーム表示名）・更新日時
- ソート: 更新日時の新しい順（固定）
- 検索: World名の部分一致（説明文は対象外）。インクリメンタル絞り込み
- 「削除済みを表示」トグル: [画面遷移-共通方針.md](../../画面遷移-共通方針.md)の共通パターン。削除済み行はグレー＋「削除済み」バッジ＋「復元」ボタン。`deleted_by`が管理者のものは表示しない（Phase 1では発生しない）
- 行クリックでSC-09へ
- 0件時: 「最初のWorldを作りましょう」＋新規作成ボタンの空状態

## 画面遷移

- **遷移元**: ログイン・登録完了後、ヘッダーの「World一覧」
- **遷移先**: 行クリック → SC-09、＋新規作成 → SC-10

1. ソートは更新日時降順で固定（並び替えUIなし）
