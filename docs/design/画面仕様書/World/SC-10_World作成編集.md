# SC-10 World作成・編集フォーム

- **URL**: `/worlds/new`・`/worlds/:id/edit`
- **区分**: C. 世界観（World）
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[World.md](../../../domain/World.md)、[User.md](../../../domain/User.md)（ペンネーム強制作成）

## 目的

Worldを作成・編集する。名義（ペンネーム）の選択・変更もここで行う。

## ワイヤーフレーム

```
┌──────────────────────────────┐
│ World作成                     │
│                              │
│ 名前 *   [                 ] │
│          残り 100 文字        │
│ 説明     [                 ] │
│          [                 ] │
│          残り 1024 文字       │
│ 表紙画像 [ファイル選択] (プレビュー)│
│ 名義 *   [星野 蒼        ▼] │
│                              │
│ [キャンセル]      [ 保存 ]    │
└──────────────────────────────┘
```

## 入力項目・バリデーション

| 項目 | 制約 |
|---|---|
| name | 必須・上限100文字（カウンタ表示）。重複チェックなし（重複許容） |
| description | 任意・上限1024文字（カウンタ表示） |
| cover_image | 任意（プレビュー表示） |
| owner_pen_name | 必須・保有ペンネームからセレクト |

## ペンネーム0件時の挙動

- フォーム表示時点でペンネーム作成モーダル（SC-07相当）を表示する
- モーダルで作成完了 → 名義欄に選択済みでセット
- モーダルを閉じた（作成しなかった）場合 → 名義欄に「ペンネームを作成してください」と表示し保存不可

## 編集モード

- 全項目変更可（**名義の変更もここから行う** — World.mdの2026-07-23決定）
- 保存でChangeLogに記録

## 画面遷移

- **遷移元**: SC-08（＋新規作成）、SC-09（編集）
- **遷移先**: 保存 → SC-09、キャンセル → 遷移元へ戻る

## 設計時の判断（要レビュー）

1. ペンネーム0件時のモーダルはフォーム表示時点で出す
