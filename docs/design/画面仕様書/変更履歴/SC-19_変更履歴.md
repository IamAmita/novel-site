# SC-19 変更履歴（ChangeLog）閲覧画面

- **URL**: `/changelog/:targetType/:targetId`（例: `/changelog/setting/42`）
- **区分**: E. 作品・執筆（ChangeLog）— **Phase 1の中核画面**
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[Novel.md](../../../domain/Novel.md) のChangeLog設計思想・決定事項

## 目的

「Gitを知らなくても、何がどう変わったかを差分で直感的に確認できる」体験を提供する。**独立画面**（2026-09-03決定）。各詳細画面（SC-09・12・16・18）の「変更履歴」ボタンから遷移する。

## ワイヤーフレーム

```
┌──────────────────────────────────────────┐
│ ← アリシア に戻る                         │
│ 変更履歴 — アリシア（Setting）            │
│                                          │
│ ● 更新  2026-09-01 21:34  星野 蒼   [▼] │
│ ├────────────────────────────────        │
│ │ 説明                                   │
│ │ - 主人公。銀髪の剣士。                  │ ← 削除色（赤）
│ │ + 主人公。銀髪の魔法剣士。              │ ← 追加色（緑）
│ │ 性格（カスタム項目）                    │
│ │ - 勝気                                 │
│ │ + 勝気だが仲間思い                      │
│ └────────────────────────────────        │
│ ● 更新  2026-08-30 10:12  星野 蒼   [▶] │
│ ● 作成  2026-08-28 09:00  星野 蒼   [▶] │
└──────────────────────────────────────────┘
```

## 一覧部分

- 対象1件（`targetType`＋`targetId`で特定）の履歴を**新しい順**の時系列リストで表示
- 各行: アクションバッジ（作成=緑／更新=青／削除=赤）・日時・変更者・展開ボタン
- 変更者はPhase 1では常に本人だが表示は残す（Phase 2の共同制作でそのまま使うため）
- 横断表示は作らない（対象ごとの絞り込みのみ、Novel.mdの決定どおり）。revert機能もなし
- ページング: 「さらに読み込む」ボタン方式

## 差分（diff）表示部分

- 行の展開で、`changes`に記録されたフィールドごとの変更前後を表示
- フィールドごとにブロックを分け、**変更前を削除色（赤背景＋`-`）、変更後を追加色（緑背景＋`+`）**で表示
- フィールド名は日本語ラベルで表示（`description`→「説明」、`body`→「本文」、`fields.性格`→「性格（カスタム項目）」）
- **長文フィールド（Episode.bodyなど）**: 全文の置き換え表示ではなく、**行単位のdiffを計算して変更のあった行の前後数行のみ表示**（GitHubのdiff表示と同じ。未変更部分は「…」で折りたたみ、クリックで展開）。diff計算はフロントエンドで変更前後の全文から行う（`changes`には全文が入っている）
- `create`は全フィールドを追加色のみ、`delete`は削除色のみで表示

## 対象タイプごとの入口と表示範囲

| 入口 | URL | 表示範囲 |
|---|---|---|
| World詳細（SC-09） | `/changelog/world/:id` | World自体の変更のみ |
| Setting詳細（SC-12) | `/changelog/setting/:id` | Setting本体＋カスタム項目（`fields.*`）の変更 |
| 作品詳細（SC-16） | `/changelog/novel/:id` | Novel自体の変更に加え、**配下のChapter・Episodeの変更もまとめて表示**（タブ切り替え:「作品情報のみ／章・話を含む」。Chapterに専用画面がないため章の履歴はここでカバー） |
| 話執筆画面（SC-18） | `/changelog/episode/:id` | Episode自体（タイトル・本文）の変更のみ |

> 注: 「作品詳細からは配下も含めて見られる」は、Novel.mdの「対象ごとの絞り込み表示のみ（World横断ページは作らない）」の決定と両立する範囲の拡張と判断した。不要なら「作品情報のみ」に縮小する。

## 画面遷移

- **遷移元**: SC-09・SC-12・SC-16・SC-18の「変更履歴」ボタン
- **遷移先**: 「← 戻る」で遷移元の詳細画面へ

## 設計時の判断（要レビュー）

1. ページングは「さらに読み込む」ボタン方式
2. 長文フィールドは行単位diff＋未変更部分の折りたたみ（GitHub方式）。diff計算はフロントエンド
3. 作品の変更履歴は配下のChapter・Episodeも含めてタブで切り替え表示
4. 変更者表示はPhase 1でも残す
