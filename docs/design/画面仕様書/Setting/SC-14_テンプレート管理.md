# SC-14 テンプレート管理画面

- **URL**: `/worlds/:id/templates`
- **区分**: D. 設定（Setting）
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[Setting.md](../../../domain/Setting.md)

## 目的

World単位でSettingTemplate・SettingTemplateFieldを管理する。World詳細（SC-09）の「設定テンプレートを管理」から遷移する（2026-09-03決定の導線）。

## ワイヤーフレーム

```
┌──────────────────────────────────────────┐
│ 設定テンプレート管理 — 異世界オルディア     │
│                          [＋テンプレート追加]│
│                                          │
│ ▼ キャラクター              [名前変更] [削除]│
│    ⋮⋮ 性格    [テキスト▼]        [削除] │
│    ⋮⋮ 所在地  [参照▼]            [削除] │
│    [＋項目を追加]                         │
│ ▶ 世界・地理                [名前変更] [削除]│
│ ▶ 組織・勢力                [名前変更] [削除]│
└──────────────────────────────────────────┘
```

## 表示要素・操作

- アコーディオン形式でテンプレートを展開し、その場で項目（SettingTemplateField: 項目名・型・並び順）の追加・編集・削除・並び替えができる
- 編集は**即時保存**（テンプレートはChangeLog対象外のため、一括保存にこだわらない）
- テンプレート名は同一World内で一意（重複時インラインエラー）
- 初期セット5種（キャラクター／世界・地理／組織・勢力／物品・アイテム／歴史。World作成時に自動生成）も同様に編集・削除可
- テンプレート削除時: 確認ダイアログ「使用中のSettingには影響しません」を表示（SET_NULL・作成時コピー方式の決定どおり、既存Settingへの影響はない）
