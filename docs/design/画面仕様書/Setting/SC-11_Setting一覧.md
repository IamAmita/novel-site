# SC-11 Setting一覧画面

- **URL**: `/settings`
- **区分**: D. 設定（Setting）／F. 閲覧・検索
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[Setting.md](../../../domain/Setting.md)、[functional-scope.md](../../../business/functional-scope.md) F

## 目的

World横断で自分のSettingをツリー一覧・検索する。「設定一覧」グローバルメニューに対応。削除済みSettingの復元もここで行う。

## ワイヤーフレーム

```
┌──────────────────────────────────────────┐
│ 設定一覧   [検索:        ]  [＋新規作成]  │
│ World: [すべて ▼]    削除済みを表示 [OFF] │
│                                          │
│ ▼ 異世界オルディア (World)               │
│   ▶ アリシア            キャラクター      │
│   ▼ 王国オルディア      組織・勢力        │
│       └ 王都グラン      世界・地理        │
│   ▶ 聖剣アリオン ※     物品・アイテム    │
│ ▶ 近未来都市トーキョー (World)            │
└──────────────────────────────────────────┘
※ = 作品専用Setting（作品名をツールチップ表示）
```

## 表示要素・操作

- **World横断**の一覧。Worldごとにグループ化し、その中で親子階層をツリー表示（初期は折りたたみ、▶で展開 — Setting.mdの決定どおり）
- Worldフィルタ: セレクトで特定Worldに絞り込み
- 検索: **名前・内容の部分一致**。「内容」はdescription＋SettingFieldのtext_valueを対象とする。検索中はツリーを解除してフラットなヒット一覧表示
- 各行: Setting名・作成元テンプレート名（あれば）・作品専用マーク（作品名ツールチップ）
- 「削除済みを表示」トグル: 共通パターンどおり（復元ボタン付き）
- 行クリックでSC-12へ

## 画面遷移

- **遷移元**: ヘッダーの「設定一覧」
- **遷移先**: 行クリック → SC-12、＋新規作成 → SC-13

## 設計時の判断（要レビュー）

1. Worldごとにグループ化＋Worldフィルタを設ける
2. 検索の「内容」はdescription＋SettingFieldのtext_valueを対象
