# SC-12 Setting詳細画面

- **URL**: `/settings/:id`
- **区分**: D. 設定（Setting）
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[Setting.md](../../../domain/Setting.md)

## 目的

Settingの内容（基本情報・カスタム項目・関係性・子Setting）を閲覧する。**閲覧専用**（フォーム集約型の2026-09-03決定どおり、編集はSC-13で行う）。例外として関係性の追加・削除のみこの画面から直接行う。

## ワイヤーフレーム

```
┌──────────────────────────────────────────┐
│ アリシア                [変更履歴] [編集]  │
│ World: 異世界オルディア ／ テンプレート: キャラクター │
│                                          │
│ 説明: 主人公。銀髪の剣士。……              │
│                                          │
│ ── カスタム項目 ──                       │
│ 性格     勝気                            │
│ 所在地   → 王都グラン        （リンク）   │
│                                          │
│ ── 関係性 ──            [＋関係を追加]   │
│ アリシア →(師匠)→ ガレオン       [削除]  │
│ カイル →(ライバル)→ アリシア     [削除]  │
│                                          │
│ ── 子Setting ──                          │
│ ・アリシアの過去                          │
│ ──────────────────────────────           │
│ [このSettingを削除]                       │
└──────────────────────────────────────────┘
```

## 表示要素・操作

- 表示: 名前・所属World・所属作品（作品専用の場合）・作成元テンプレート・説明・カスタム項目（order順）・関係性（from/to両方向）・子Setting一覧
- `setting_reference`型の項目は参照先Setting詳細（SC-12）へのリンク
- 関係性の表示: 方向を矢印で表現（例: `アリシア →(師匠)→ ガレオン` ＝「アリシアの師匠はガレオン」）。ラベルNULLは「(ラベルなし)」
- 変更履歴ボタン: SC-19（`/changelog/setting/:id`）へ。SettingFieldの変更も統合表示される
- 削除ボタンはページ下部に分離配置 → DL-02

## 関連ダイアログ

### DL-02 Setting削除確認

- 「『（Setting名）』を削除しますか？」＋補足「子Settingも一緒に削除されます（あとから復元できます）」＋「キャンセル／削除する」
- 子Setting・SettingFieldは連鎖削除（論理削除）。削除後はSC-11へ

### DL-04 関係性の追加

```
┌──────────────────────────────┐
│ 関係を追加                    │
│                              │
│ 方向: (●) アリシア → 相手     │
│       (○) 相手 → アリシア     │
│ 相手のSetting * [検索して選択▼]│
│ ラベル [師匠 ▼] [＋新規ラベル] │
│                              │
│ [キャンセル]      [ 追加 ]    │
└──────────────────────────────┘
```

- 方向: ラジオボタンで「このSetting→相手」「相手→このSetting」
- 相手のSetting: 検索付きセレクト。World横断で選択可（自分の全Setting。Phase 1では他ユーザーのSettingは対象外 — 公開機能がないため）
- ラベル: 既存RelationLabelからセレクト、または「＋新規ラベル」でその場に入力欄を出して追加。未選択（ラベルなし）も可
- 既存関係の削除は一覧の各行の削除ボタンから即実行（確認ダイアログなし）

## 画面遷移

- **遷移元**: SC-11（行クリック）、SC-12（参照リンク・子Setting）、SC-18（サイドパネルから）
- **遷移先**: 変更履歴 → SC-19、編集 → SC-13、削除 → SC-11

## 設計時の判断（要レビュー）

1. 関係性の追加・削除はこの画面から直接行う（SettingRelationは独立モデルでSetting本体のdiffに含まれないため、フォーム一括保存の枠外とする）
2. 関係の削除は確認ダイアログなし
