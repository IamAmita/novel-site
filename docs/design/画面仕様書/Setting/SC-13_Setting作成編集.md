# SC-13 Setting作成・編集フォーム

- **URL**: `/settings/new`・`/settings/:id/edit`
- **区分**: D. 設定（Setting）
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[Setting.md](../../../domain/Setting.md)

## 目的

**フォーム集約型**（2026-09-03決定）: 基本情報とカスタム項目を1画面でまとめて編集し、一括保存する。1回の保存＝1つのChangeLogレコード（diff）となり、コミット履歴的な差分表示と整合する。

## ワイヤーフレーム

```
┌──────────────────────────────────────────┐
│ Setting作成                               │
│                                          │
│ 所属World *   [異世界オルディア ▼]        │
│ 所属作品      [（World全体で共有）▼]      │
│ 親Setting     [なし ▼]                   │
│ テンプレート   [キャラクター ▼] ←作成時のみ│
│ 名前 *        [                        ] │
│ 説明          [                        ] │
│                                          │
│ ── カスタム項目 ──                       │
│ ⋮⋮ 性格   [テキスト▼] [勝気      ] [削除]│
│ ⋮⋮ 所在地 [参照▼]   [王都グラン ▼] [削除]│
│ [＋項目を追加]                            │
│                                          │
│ [キャンセル]                  [ 保存 ]    │
└──────────────────────────────────────────┘
```

## 基本情報の入力項目

| 項目 | 制約 |
|---|---|
| 所属World | 必須。**編集時は変更不可**（配下の参照整合が壊れるため） |
| 所属作品 | 任意。選択肢は所属Worldの作品のみ。未選択=World全体で共有 |
| 親Setting | 任意。**スコープ制約**: 選択肢は「同一World内で、スコープが同じか広い」Settingのみに絞る（Setting.mdの2026-08-22決定） |
| テンプレート | 任意・**作成時のみ表示**。選択するとその項目が下のカスタム項目欄に即座にコピーされる。選択し直すと確認の上で入れ替え |
| 名前 | 必須。重複許容（チェックなし） |
| 説明 | 任意 |

## カスタム項目の編集

- 各行: ドラッグハンドル（並び替え）・項目名・型（テキスト／他Setting参照）・値・削除ボタン
- 型が「参照」の場合、値はSetting選択（検索付きセレクト）。1項目1値（Setting.mdの決定どおり）
- 「＋項目を追加」で行を追加。テンプレート由来の項目も自由に編集・削除できる

## 保存

- 保存時にまとめてバリデーション → Setting本体＋SettingFieldを一括保存（1つのChangeLogレコード） → SC-12へ

## 画面遷移

- **遷移元**: SC-11（＋新規作成）、SC-12（編集）
- **遷移先**: 保存 → SC-12、キャンセル → 遷移元へ戻る

## 設計時の判断（要レビュー）

1. 所属Worldは編集時に変更不可
