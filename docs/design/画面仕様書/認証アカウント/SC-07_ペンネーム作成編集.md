# SC-07 ペンネーム作成・編集フォーム

- **URL**: `/pennames/new`・`/pennames/:id/edit`
- **区分**: B. ユーザー・ペンネーム管理
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[User.md](../../../domain/User.md)

## 目的

ペンネームを作成・編集する。World作成時の強制作成フロー（モーダル）でも同じフォーム内容を使う。

## ワイヤーフレーム

```
┌──────────────────────────┐
│ ペンネーム作成            │
│                          │
│ 表示名 * [             ] │
│ アイコン (○) [ファイル選択]│
│ 自己紹介 [             ] │
│          残り 1024 文字   │
│                          │
│ [キャンセル]  [ 保存 ]    │
└──────────────────────────┘
```

## 入力項目・バリデーション

| 項目 | 制約 |
|---|---|
| display_name | 必須・**同一ユーザー内で一意**（重複時はインラインエラー）。異なるユーザー間の重複は許容 |
| icon | 任意 |
| bio | 任意・上限1024文字（カウンタ表示） |

- User情報からの初期値コピーは行わない（User/PenName完全分離の方針）

## World作成時の強制作成フロー（モーダル版）

- World作成フォーム（SC-10）でペンネームが0件の場合、このフォームと同内容の**モーダル**を表示する
- 作成完了後はWorld作成フォームに戻り、作成したペンネームが名義として選択済みの状態にする（ページ遷移させず、入力中のWorld情報を保持する）

## 画面遷移

- **遷移元**: SC-06（新規作成・編集）、SC-10（ペンネーム0件時のモーダル）
- **遷移先**: 保存・キャンセル → SC-06（モーダル版はSC-10に留まる）

## 設計時の判断（要レビュー）

1. World作成時の強制作成は**モーダル**で行い、入力中のWorld情報を保持する
