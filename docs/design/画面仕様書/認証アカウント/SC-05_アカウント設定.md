- **URL**: `/account`
- **区分**: B. ユーザー・ペンネーム管理
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[User.md](../../../domain/User.md)、[Phase1-確定メモ.md](../../../project/Phase1-確定メモ.md) §3.3

## 目的

アカウント情報（username・icon・bio）の編集と、アカウント削除を行う。

## ワイヤーフレーム

```
┌────────────────────────────────┐
│ アカウント設定                   │
│                                │
│ ユーザーID:  @kizm   （変更不可）│
│ メールアドレス: k***@icloud.com │
│ ──────────────────────────     │
│ ユーザー名 [            ]      │
│ アイコン   (○) [ファイル選択]   │
│ 自己紹介   [               ]   │
│            [               ]   │
│            残り 1024 文字       │
│                    [ 保存 ]    │
│ ──────────────────────────     │
│ 危険な操作                      │
│ [アカウントを削除する]           │
└────────────────────────────────┘
```

## 表示要素・操作

- **表示のみ**: user_id・email
- **編集可**: username（必須）・icon（任意）・bio（任意・上限1024文字・カウンタ表示）
- パスワード変更は置かない（Phase 1見送り、2026-09-03決定）
- アカウント削除はページ最下部の「危険な操作」に分離配置 → DL-06

## 関連ダイアログ: DL-06 アカウント削除確認

- 「アカウントを削除しますか？」＋補足「ペンネーム・World・設定・作品などすべてのデータが削除されます」＋「キャンセル／削除する」
- 誤操作防止のため、確認欄にユーザーIDの入力を求める（GitHubのリポジトリ削除方式）
- 削除は論理削除。配下データ（ペンネーム・World・作品等）は連鎖的に論理削除
- 削除実行後はログアウトし、SC-02へ

## 画面遷移

- **遷移元**: ヘッダーの「アカウント▼」ドロップダウン
- **遷移先**: アカウント削除 → SC-02 ログイン
