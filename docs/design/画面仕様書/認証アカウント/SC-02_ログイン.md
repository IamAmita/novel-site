# SC-02 ログイン画面

- **URL**: `/login`
- **区分**: B. ユーザー・ペンネーム管理
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[User.md](../../../domain/User.md)、[Phase1-確定メモ.md](../../../project/Phase1-確定メモ.md) §3.3

## 目的

メールアドレスまたはユーザーID＋パスワードでログインする（Django標準認証）。

## ワイヤーフレーム

```
┌──────────────────────────┐
│         ログイン          │
│                          │
│ メールアドレス            │
│ またはユーザーID          │
│ [                      ] │
│ パスワード                │
│ [                      ] │
│                          │
│ [      ログインする     ] │
│ 登録はこちら → /register  │
└──────────────────────────┘
```

## 表示要素・操作

- 識別子欄は1つ。入力値に`@`が含まれるかどうかでemail／user_idを判別する
- パスワードリセットへの導線は**置かない**（Phase 1では機能自体が存在しないため。[Phase1-確定メモ.md](../../../project/Phase1-確定メモ.md) §3.3）
- 認証失敗時はフォーム上部に「メールアドレス（またはユーザーID）かパスワードが違います」を表示

## 画面遷移

- **遷移元**: 未ログイン時の全URL（リダイレクト先）、SC-01（「ログインはこちら」リンク）
- **遷移先**: ログイン成功 → SC-08 World一覧

## 設計時の判断（要レビュー）

1. ログイン識別子は`@`の有無でemail／user_idを自動判別する（切り替えタブは設けない）
