# SC-06 ペンネーム一覧画面

- **URL**: `/pennames`
- **区分**: B. ユーザー・ペンネーム管理
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[User.md](../../../domain/User.md)

## 目的

保有するペンネームを一覧し、作成・編集・削除の起点となる。

## ワイヤーフレーム

```
┌────────────────────────────────┐
│ ペンネーム        [＋新規作成]  │
│                                │
│ (○) 星野 蒼   World: 2 [編集] [削除] │
│ (○) 月宮 かなた World: 0 [編集] [削除] │
└────────────────────────────────┘
```

## 表示要素・操作

- 表示: アイコン・表示名・所属World数のみ（**シンプルな一覧**、User.mdの2026-08-22決定どおり。作品数等の統計は含めない）
- 「削除」はWorldを1件でも保持しているペンネームでは**非活性**にし、ツールチップで理由（「Worldを保持しているため削除できません」）を表示。押せる場合はDL-05へ
- 0件時は空状態メッセージ「ペンネームはWorld作成時にも作成できます」＋新規作成ボタン

## 関連ダイアログ: DL-05 ペンネーム削除確認

- 「（表示名）を削除しますか？」＋「キャンセル／削除する」
- Worldを保持している場合はそもそもこのダイアログに到達しない（ボタン非活性）

## 画面遷移

- **遷移元**: ヘッダーの「ペンネーム」
- **遷移先**: ＋新規作成 → SC-07（作成）、編集 → SC-07（編集）
