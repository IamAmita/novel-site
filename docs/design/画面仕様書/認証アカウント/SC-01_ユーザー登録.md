# SC-01 ユーザー登録画面

- **URL**: `/register`
- **区分**: B. ユーザー・ペンネーム管理
- **作成日**: 2026-09-03　**ステータス**: ドラフト
- **根拠**: [画面一覧.md](../../画面一覧.md)、[User.md](../../../domain/User.md)、[Phase1-確定メモ.md](../../../project/Phase1-確定メモ.md) §3.3

## 目的

アカウントを新規作成する。メール確認（verification）は行わず、登録成功で即ログイン状態にする。

## ワイヤーフレーム

```
┌──────────────────────────┐
│        ユーザー登録        │
│                          │
│ メールアドレス *          │
│ [                      ] │
│ ユーザーID *（変更不可）   │
│ [                      ] │
│ 英数字・_、3〜20文字       │
│ ユーザー名 *              │
│ [                      ] │
│ パスワード *              │
│ [                      ] │
│                          │
│ [       登録する       ] │
│ ログインはこちら → /login │
└──────────────────────────┘
```

## 入力項目・バリデーション

| 項目 | 制約 |
|---|---|
| email | 必須・一意 |
| user_id | 必須・一意・英数字とアンダースコアのみ・3〜20文字。**登録後変更不可である旨を欄の下に明記** |
| username | 必須・重複可 |
| password | 必須。Django標準のバリデーション（最低8文字・数字のみ不可等）を使用 |

- icon・bioは登録時には入力させない（SC-05で後から設定）
- 登録時にペンネームは作成しない（0件が正常状態）

## 画面遷移

- **遷移元**: SC-02（「登録はこちら」リンク）、未ログイン時のヘッダー
- **遷移先**: 登録成功 → SC-08 World一覧（即ログイン状態）
