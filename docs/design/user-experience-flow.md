# ユーザー体験フロー

**目的**: 技術に依存しないUXの基本設計  
**対象**: 全実装で統一すべきユーザー体験

---

## 🎯 主要ユーザーフロー

### 新規ユーザー登録フロー
1. トップページ訪問
2. 「新規登録」ボタンクリック
3. メールアドレス・パスワード入力
4. 利用規約同意・確認
5. 確認メール送信・クリック
6. 登録完了・ログイン状態

### 小説投稿フロー
1. 「作品投稿」メニュー選択
2. 基本情報入力（タイトル・あらすじ）
3. 第1話の本文入力
4. 公開設定選択
5. プレビュー確認
6. 投稿完了・公開

### 読書体験フロー
1. 作品検索・一覧から選択
2. 作品詳細・あらすじ確認
3. 第1話から読書開始
4. 縦書き・横書き切替
5. ページ送り・次話移動
6. コメント・評価投稿

---

## 💡 UX設計原則

### ユーザビリティ
- 3クリック以内で主要機能にアクセス
- 明確なナビゲーション・パンくずリスト
- 操作の取り消し・やり直し機能

### アクセシビリティ
- キーボード操作対応
- スクリーンリーダー対応
- 十分なコントラスト比

### レスポンシブ対応
- モバイル・タブレット・デスクトップ
- タッチ操作・マウス操作両対応

---

**実装指針**: 各フレームワークの特性を活かしたUI実装
